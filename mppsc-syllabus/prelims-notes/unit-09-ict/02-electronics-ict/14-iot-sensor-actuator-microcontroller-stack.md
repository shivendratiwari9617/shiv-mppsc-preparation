# IoT — सेंसर/एक्चुएटर/माइक्रोकंट्रोलर — स्टैक

**स्रोत:** मानक इलेक्ट्रॉनिक्स/एम्बेडेड-सिस्टम संदर्भ (IoT Architecture Fundamentals — स्थिर/सार्वभौमिक-तकनीकी-ज्ञान)

## 1. IoT (Internet of Things) — परिभाषा

- **IoT — भौतिक-वस्तुओं (उपकरण/वाहन/मशीन) को सेंसर, सॉफ़्टवेयर एवं नेटवर्क-कनेक्टिविटी से युक्त कर, इंटरनेट के माध्यम से डेटा-आदान-प्रदान/नियंत्रण-योग्य बनाने की प्रणाली।**

## 2. IoT का तकनीकी-स्टैक — 4 मूल-घटक (अत्यंत उच्च-प्राथमिकता)

| घटक | कार्य | उदाहरण |
|---|---|---|
| **सेंसर (Sensor)** | भौतिक-वातावरण से डेटा एकत्रित करना (इनपुट) | तापमान/आर्द्रता/गति/प्रकाश/निकटता-सेंसर |
| **माइक्रोकंट्रोलर (Microcontroller)** | सेंसर-डेटा को प्रोसेस करना, निर्णय लेना — "IoT-डिवाइस का मस्तिष्क" | Arduino, ESP32/ESP8266, Raspberry Pi Pico |
| **एक्चुएटर (Actuator)** | निर्णय के आधार पर भौतिक-क्रिया सम्पन्न करना (आउटपुट) | मोटर, वाल्व, LED, रिले-स्विच |
| **कनेक्टिविटी-मॉड्यूल** | डेटा को क्लाउड/नेटवर्क तक पहुँचाना | Wi-Fi, ब्लूटूथ, ज़िगबी (Zigbee), सेल्युलर-मॉड्यूल |

- **कार्य-प्रवाह — सेंसर(डेटा-संग्रहण) → माइक्रोकंट्रोलर(प्रसंस्करण/निर्णय) → एक्चुएटर(भौतिक-क्रिया) — एवं समानांतर-रूप से कनेक्टिविटी-मॉड्यूल द्वारा डेटा क्लाउड को प्रेषित** — एक सामान्य-उदाहरण: स्मार्ट-थर्मोस्टेट — तापमान-सेंसर(इनपुट)→माइक्रोकंट्रोलर(तुलना-निर्णय)→AC-कम्प्रेसर एक्चुएटर(चालू/बंद)।

## 3. माइक्रोकंट्रोलर बनाम माइक्रोप्रोसेसर (महत्वपूर्ण-भेद, MCQ-योग्य)

- **माइक्रोकंट्रोलर (MCU)** — एक-ही-चिप पर CPU + मेमोरी (RAM/ROM) + इनपुट-आउटपुट-पिन सब-कुछ एकीकृत — छोटे, विशिष्ट-कार्य-केंद्रित एम्बेडेड-सिस्टम हेतु (उदा. IoT-डिवाइस)।
- **माइक्रोप्रोसेसर (CPU)** — केवल प्रोसेसिंग-यूनिट, बाह्य-मेमोरी/इनपुट-आउटपुट-घटकों की आवश्यकता — सामान्य-प्रयोजन-कंप्यूटिंग हेतु (उदा. लैपटॉप/डेस्कटॉप)।

## 4. IoT की स्तरीकृत-वास्तुकला (Layered Architecture) — संक्षिप्त

- **धारणा-स्तर (Perception Layer)** — सेंसर/एक्चुएटर (भौतिक-दुनिया से डेटा-संग्रहण); **नेटवर्क-स्तर (Network Layer)** — डेटा-संचरण (Wi-Fi/सेल्युलर/प्रोटोकॉल — checklist-अगला-बिंदु); **एप्लिकेशन-स्तर (Application Layer)** — डेटा-विश्लेषण/उपयोगकर्ता-अंतरफलक (डैशबोर्ड/ऐप)।

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **IoT-स्टैक-4-घटक — सेंसर(इनपुट)/माइक्रोकंट्रोलर(प्रसंस्करण)/एक्चुएटर(आउटपुट)/कनेक्टिविटी(क्लाउड-संचरण)**।
- **माइक्रोकंट्रोलर(CPU+मेमोरी+I/O एकीकृत, एम्बेडेड-हेतु) बनाम माइक्रोप्रोसेसर(केवल-CPU, सामान्य-कंप्यूटिंग-हेतु)**।
- **3-स्तरीय-वास्तुकला — धारणा(सेंसर)/नेटवर्क(संचरण)/एप्लिकेशन(विश्लेषण-प्रदर्शन)**।
