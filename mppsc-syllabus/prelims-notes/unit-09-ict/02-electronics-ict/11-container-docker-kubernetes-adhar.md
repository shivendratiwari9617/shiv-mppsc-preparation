# कंटेनर — Docker/Kubernetes — आधार

**स्रोत:** मानक क्लाउड-नेटिव/DevOps संदर्भ (Container Orchestration Fundamentals — स्थिर/सार्वभौमिक-तकनीकी-ज्ञान)

## 1. कंटेनर की अवधारणा (पुनर्स्मरण — checklist-फ़ाइल 01, बिंदु 5 से सम्बद्ध)

- **कंटेनर — किसी एप्लिकेशन एवं उसकी सभी-निर्भरताओं (dependencies — लाइब्रेरी/कॉन्फ़िगरेशन) को एक हल्के, पोर्टेबल (portable) पैकेज में समाहित करने की तकनीक** — मेज़बान (host) OS का कर्नेल साझा करता है (पृथक-OS की आवश्यकता नहीं, VM के विपरीत) — "एक-बार-बनाओ, कहीं-भी-चलाओ (build once, run anywhere)" सिद्धांत।

## 2. Docker — कंटेनराइज़ेशन-प्लेटफ़ॉर्म

- **Docker — सर्वाधिक-लोकप्रिय, ओपन-सोर्स कंटेनराइज़ेशन-प्लेटफ़ॉर्म** — एप्लिकेशन को "Docker Image" (एक स्थिर, निष्पादन-योग्य पैकेज) में बनाना, एवं उस इमेज से "Docker Container" (चालू/निष्पादित इंस्टेंस) चलाना।
- **Dockerfile** — कंटेनर-इमेज बनाने हेतु चरणबद्ध-निर्देशों वाली टेक्स्ट-फ़ाइल; **Docker Hub** — पूर्व-निर्मित-इमेज साझा करने हेतु सार्वजनिक-रिपॉज़िटरी।

## 3. Kubernetes (K8s) — कंटेनर-ऑर्केस्ट्रेशन (अत्यंत उच्च-प्राथमिकता)

- **Kubernetes (संक्षिप्त "K8s" — 8 अक्षर "ubernete" के प्रतिस्थापन-स्वरूप) — मूलतः Google द्वारा विकसित, ओपन-सोर्स कंटेनर-ऑर्केस्ट्रेशन-प्लेटफ़ॉर्म** — बड़े-पैमाने पर एकाधिक-कंटेनरों के **स्वचालित-परिनियोजन (deployment), मापन (scaling), प्रबंधन एवं स्वास्थ्य-निगरानी (health monitoring)** हेतु।
- **मुख्य-आवश्यकता क्यों?** — जब किसी एप्लिकेशन में सैकड़ों/हज़ारों कंटेनर एक-साथ चल रहे हों, तो उन्हें मैन्युअल-रूप से प्रबंधित करना असम्भव — Kubernetes स्वचालित-रूप से **लोड-बैलेंसिंग, स्व-उपचार (self-healing — विफल-कंटेनर को स्वतः पुनः-प्रारम्भ करना), स्वतः-मापन (auto-scaling)** प्रदान करता है।
- **मूल-शब्दावली — Pod** (Kubernetes की सबसे-छोटी परिनियोजन-इकाई, एक/एकाधिक कंटेनर समाहित); **Node** (एक भौतिक/वर्चुअल-मशीन, जिस पर Pods चलते हैं); **Cluster** (एकाधिक Nodes का समूह, Kubernetes द्वारा प्रबंधित)।

## 4. Docker बनाम Kubernetes — भ्रम-स्पष्टीकरण (अत्यंत महत्वपूर्ण MCQ-ट्रैप)

- **Docker एवं Kubernetes प्रतिस्पर्धी नहीं, अपितु पूरक (complementary) हैं — Docker कंटेनर "बनाता" है, Kubernetes उन कंटेनरों को बड़े-पैमाने पर "प्रबंधित/ऑर्केस्ट्रेट" करता है।** यह भेद परीक्षा में अक्सर ग़लत-समझा जाता है।

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **कंटेनर — हल्का, पोर्टेबल, कर्नेल-साझा-पैकेज (checklist-01/बिंदु-5 से सम्बद्ध)**।
- **Docker — कंटेनर बनाने/चलाने का प्लेटफ़ॉर्म (Image→Container, Dockerfile, Docker Hub)**।
- **Kubernetes(K8s) — कंटेनर-ऑर्केस्ट्रेशन, मूलतः Google-विकसित; Pod/Node/Cluster शब्दावली; स्वचालित-मापन/स्व-उपचार/लोड-बैलेंसिंग**।
- **Docker=बनाना, Kubernetes=प्रबंधित-करना — पूरक, प्रतिस्पर्धी नहीं**।
