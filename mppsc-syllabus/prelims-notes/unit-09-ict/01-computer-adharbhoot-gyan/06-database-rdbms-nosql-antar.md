# डेटाबेस — RDBMS/NoSQL — अंतर

**स्रोत:** NCERT कक्षा-XII कंप्यूटर विज्ञान/इन्फॉर्मेटिक्स प्रैक्टिसेज़ (Database Concepts)

## 1. DBMS की मूल-अवधारणा

- **DBMS (Database Management System)** — डेटा के संग्रहण, पुनर्प्राप्ति, प्रबंधन एवं सुरक्षा हेतु सॉफ़्टवेयर — फ़ाइल-सिस्टम की अतिरेक (redundancy)/असंगति (inconsistency) की समस्याओं का समाधान करता है।

## 2. RDBMS — मूल-अवधारणाएँ

- **RDBMS (Relational DBMS)** — डेटा को **तालिकाओं (tables/relations)** में पंक्तियों (rows/tuples) एवं स्तंभों (columns/attributes) के रूप में संग्रहीत करता है — तालिकाओं के मध्य **"कुंजी" (key)** के माध्यम से सम्बन्ध (relationship) स्थापित होता है।
- **प्राइमरी-की (Primary Key)** — प्रत्येक-पंक्ति की विशिष्ट-पहचान, NULL अथवा दोहराव-रहित; **फ़ॉरेन-की (Foreign Key)** — एक तालिका का स्तंभ जो दूसरी तालिका की प्राइमरी-की को सन्दर्भित करता है — तालिकाओं के मध्य सम्बन्ध का आधार।
- **नॉर्मलाइज़ेशन (Normalization)** — डेटा-अतिरेक/असंगति घटाने हेतु तालिकाओं को व्यवस्थित करने की प्रक्रिया — **1NF, 2NF, 3NF, BCNF** क्रमिक-स्तर।
- **ACID गुण (लेन-देन/Transaction की विश्वसनीयता हेतु):** **Atomicity (सभी-या-कुछ-नहीं), Consistency (नियम-अनुरूपता), Isolation (एक-दूसरे से स्वतंत्र-निष्पादन), Durability (स्थायित्व — एक-बार commit होने पर डेटा सुरक्षित)**।

## 3. NoSQL — मूल-अवधारणा एवं प्रकार

- **NoSQL ("Not Only SQL")** — गैर-रिलेशनल/स्कीमा-रहित (schema-less/flexible-schema) डेटाबेस — बड़ी-मात्रा, असंरचित/अर्ध-संरचित डेटा हेतु उपयुक्त।
- **NoSQL के 4 प्रमुख-प्रकार:**
  1. **डॉक्यूमेंट-आधारित** — JSON/BSON-सदृश डॉक्यूमेंट में डेटा (उदा. MongoDB)।
  2. **की-वैल्यू-आधारित** — सरल key-value जोड़े (उदा. Redis, DynamoDB)।
  3. **कॉलम-आधारित (Wide-Column)** — बड़े-पैमाने-डेटा हेतु स्तंभ-परिवार (उदा. Cassandra, HBase)।
  4. **ग्राफ़-आधारित** — नोड्स एवं एजेस से सम्बन्ध-प्रधान-डेटा (उदा. Neo4j)।

## 4. RDBMS बनाम NoSQL — तुलनात्मक-तालिका (अत्यंत उच्च-प्राथमिकता)

| आधार | RDBMS | NoSQL |
|---|---|---|
| **स्कीमा** | निश्चित/पूर्व-परिभाषित (fixed schema) | परिवर्ती/स्कीमा-रहित (dynamic/flexible) |
| **डेटा-संरचना** | संरचित (tables) | असंरचित/अर्ध-संरचित (document/key-value/graph) |
| **मापनीयता (Scalability)** | वर्टिकल (शक्तिशाली-सर्वर जोड़कर) | होरिज़ॉन्टल (अधिक-सर्वर जोड़कर, distributed) |
| **लेन-देन-गारंटी** | ACID-अनुपालित | प्रायः BASE-मॉडल (Basically Available, Soft-state, Eventually consistent) |
| **उदाहरण** | MySQL, Oracle, PostgreSQL, SQL Server | MongoDB, Cassandra, Redis, Neo4j |

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **RDBMS — तालिका-आधारित, प्राइमरी/फ़ॉरेन-की, ACID, निश्चित-स्कीमा** (MySQL/Oracle/PostgreSQL)।
- **NoSQL — 4 प्रकार (डॉक्यूमेंट/की-वैल्यू/कॉलम/ग्राफ़), स्कीमा-रहित, BASE-मॉडल, होरिज़ॉन्टल-मापनीयता** (MongoDB/Cassandra/Redis/Neo4j)।
- **ACID — Atomicity/Consistency/Isolation/Durability**।
