# CPU आर्किटेक्चर — ALU/कंट्रोल यूनिट/रजिस्टर — आधार

**स्रोत:** NCERT कक्षा-XI कंप्यूटर विज्ञान (Computer System Overview)

## 1. CPU के तीन मुख्य-घटक

- **CPU (Central Processing Unit) — कंप्यूटर का "मस्तिष्क"** — तीन प्रमुख-उप-इकाइयों से मिलकर बना:
  1. **ALU (Arithmetic Logic Unit)** — सभी अंकगणितीय (जोड़/घटाव/गुणा/भाग) एवं तार्किक (AND/OR/NOT/तुलना) संक्रियाएँ सम्पन्न करती है।
  2. **CU (Control Unit)** — निर्देशों (instructions) को डिकोड कर अन्य-घटकों (मेमोरी/ALU/I-O) के मध्य **डेटा-प्रवाह एवं संचालन-अनुक्रम को नियंत्रित/समन्वित** करती है — स्वयं कोई डेटा-प्रोसेसिंग नहीं करती।
  3. **रजिस्टर (Registers)** — CPU के भीतर स्थित **सबसे तेज़, सीमित-क्षमता की अस्थायी-भंडारण-इकाइयाँ**।

## 2. प्रमुख-रजिस्टर — नाम एवं कार्य (अत्यंत उच्च-प्राथमिकता, MCQ-योग्य)

| रजिस्टर | पूर्ण-नाम | कार्य |
|---|---|---|
| **PC** | Program Counter | अगले-निष्पादित होने वाले निर्देश का पता (address) रखता है |
| **IR** | Instruction Register | वर्तमान में निष्पादित हो रहे निर्देश को रखता है |
| **MAR** | Memory Address Register | उस मेमोरी-पते को रखता है, जिस तक पहुँचा जाना है |
| **MDR/MBR** | Memory Data/Buffer Register | मेमोरी से पढ़े/लिखे जा रहे डेटा को रखता है |
| **AC** | Accumulator | ALU-संक्रियाओं के मध्यवर्ती-परिणाम रखता है |

## 3. फ़ेच-डिकोड-एक्ज़ीक्यूट चक्र (Instruction Cycle)

- **अत्यंत उच्च-प्राथमिकता तथ्य: प्रत्येक निर्देश के निष्पादन में 3 मुख्य-चरण — (1) फ़ेच (Fetch) — मेमोरी से निर्देश PC के पते से लाना, (2) डिकोड (Decode) — CU द्वारा निर्देश का अर्थ-निर्धारण, (3) एक्ज़ीक्यूट (Execute) — ALU/अन्य-घटकों द्वारा वास्तविक-क्रियान्वयन** — इसे "FDE साइकल" भी कहते हैं।

## 4. क्लॉक-स्पीड एवं प्रदर्शन-मापन

- **क्लॉक-स्पीड — हर्ट्ज़ (Hz) में मापी जाती है** — GHz (गीगाहर्ट्ज़) = 10⁹ चक्र/सेकंड — प्रति-सेकंड सम्पन्न-होने-वाले घड़ी-चक्रों (clock cycles) की संख्या दर्शाती है।
- **MIPS (Million Instructions Per Second)** — प्रोसेसर-गति मापने की एक अन्य-इकाई।

## 5. बस (Bus) — घटकों के मध्य संचार-मार्ग

- **डेटा बस** — वास्तविक-डेटा का स्थानांतरण; **एड्रेस बस** — मेमोरी-पते का प्रसारण (एकदिश/unidirectional); **कंट्रोल बस** — नियंत्रण-संकेत (Read/Write आदि) वहन करती है।

## 6. मल्टी-कोर एवं समांतर-प्रोसेसिंग (आधुनिक-विस्तार)

- **मल्टी-कोर प्रोसेसर** — एक ही चिप पर 2 (Dual-core), 4 (Quad-core) अथवा अधिक स्वतंत्र-प्रोसेसिंग-इकाइयाँ (कोर) — समांतर-रूप से एकाधिक-कार्य/थ्रेड सम्पन्न करने में सक्षम, एकल-कोर की तुलना में दक्षता-वृद्धि।

## 7. परीक्षा-केंद्रित सार (Quick Revision)

- **CPU = ALU(गणना)+CU(नियंत्रण)+रजिस्टर(अस्थायी-भंडारण)**।
- **रजिस्टर — PC(अगला-पता), IR(वर्तमान-निर्देश), MAR(मेमोरी-पता), MDR(डेटा), AC(मध्यवर्ती-परिणाम)**।
- **FDE साइकल — Fetch→Decode→Execute**।
- **क्लॉक-स्पीड — Hz/GHz में**; बस — डेटा/एड्रेस/कंट्रोल (3 प्रकार)।
- **मल्टी-कोर — एक चिप पर बहु-प्रोसेसिंग-इकाइयाँ**।
