# एप्लिकेशन सुरक्षा — OWASP टॉप-10

**स्रोत:** OWASP (Open Web Application Security Project) आधिकारिक-दस्तावेज़ — स्थिर/सार्वभौमिक-मानक-सूची (2021-संस्करण, वर्तमान-मानक)

## 1. OWASP क्या है?

- **OWASP (Open Worldwide Application Security Project) — एक गैर-लाभकारी अंतरराष्ट्रीय-संगठन, जो वेब-एप्लिकेशन-सुरक्षा में सुधार हेतु निःशुल्क/खुले संसाधन/उपकरण/दस्तावेज़ प्रदान करता है।**
- **"OWASP टॉप-10"** — वेब-एप्लिकेशन में पाई जाने वाली सर्वाधिक-गंभीर/सामान्य सुरक्षा-जोखिमों की एक व्यापक-रूप-से-मान्यता-प्राप्त सूची — समय-समय पर अद्यतन (नवीनतम-संस्करण 2021)।

## 2. OWASP टॉप-10 (2021) — सूची (अत्यंत उच्च-प्राथमिकता, MCQ-योग्य)

| क्रम | जोखिम | संक्षिप्त-विवरण |
|---|---|---|
| A01 | **Broken Access Control** | उपयोगकर्ता को अनुचित-रूप से ऐसे संसाधनों तक पहुँच मिल जाना, जिसकी उसे अनुमति नहीं थी |
| A02 | **Cryptographic Failures** | कमज़ोर/अनुपस्थित-एन्क्रिप्शन से संवेदनशील-डेटा उजागर होना |
| A03 | **Injection** | अविश्वसनीय-इनपुट के माध्यम से दुर्भावनापूर्ण-कोड निष्पादित करना — **SQL Injection सबसे-प्रसिद्ध-उदाहरण** |
| A04 | **Insecure Design** | मूल-डिज़ाइन-चरण में ही सुरक्षा-दोष होना |
| A05 | **Security Misconfiguration** | ग़लत/असुरक्षित-कॉन्फ़िगरेशन (checklist-फ़ाइल-02/बिंदु-12 क्लाउड-सुरक्षा से सम्बद्ध) |
| A06 | **Vulnerable and Outdated Components** | पुराने/असुरक्षित-सॉफ़्टवेयर-घटकों का उपयोग |
| A07 | **Identification and Authentication Failures** | कमज़ोर-प्रमाणीकरण-व्यवस्था (checklist-बिंदु-8 से सम्बद्ध) |
| A08 | **Software and Data Integrity Failures** | अविश्वसनीय-स्रोतों से सॉफ़्टवेयर/डेटा-अद्यतन (सप्लाई-चेन-हमले) |
| A09 | **Security Logging and Monitoring Failures** | पर्याप्त-लॉगिंग/निगरानी न होने से हमले का पता देर से चलना |
| A10 | **Server-Side Request Forgery (SSRF)** | सर्वर को धोखे से अनधिकृत-आंतरिक/बाह्य-अनुरोध भेजने हेतु प्रेरित करना |

## 3. SQL Injection — सर्वाधिक-प्रसिद्ध-उदाहरण (विस्तृत)

- **SQL Injection — जब कोई एप्लिकेशन उपयोगकर्ता-इनपुट को उचित-रूप से "सैनिटाइज़" (साफ़/सत्यापित) किए बिना, सीधे SQL-क्वेरी (checklist-फ़ाइल-01/बिंदु-7) में जोड़ देता है — हमलावर विशेष-रूप से तैयार-किया इनपुट डालकर, डेटाबेस से अनधिकृत-डेटा प्राप्त/परिवर्तित/हटा सकता है।**
- **रोकथाम — "पैरामीटराइज़्ड क्वेरी"/"प्रीपेयर्ड स्टेटमेंट" का उपयोग (उपयोगकर्ता-इनपुट को कभी सीधे-क्वेरी में न जोड़ना)।**

## 4. परीक्षा-केंद्रित सार (Quick Revision)

- **OWASP — वेब-एप्लिकेशन-सुरक्षा हेतु अंतरराष्ट्रीय गैर-लाभकारी-संगठन; टॉप-10 = 10 सर्वाधिक-गंभीर-जोखिमों की मानक-सूची**।
- **शीर्ष-3 (2021) — Broken Access Control > Cryptographic Failures > Injection**।
- **SQL Injection — इनपुट-असैनिटाइज़ेशन से डेटाबेस-शोषण; समाधान — पैरामीटराइज़्ड-क्वेरी**।
