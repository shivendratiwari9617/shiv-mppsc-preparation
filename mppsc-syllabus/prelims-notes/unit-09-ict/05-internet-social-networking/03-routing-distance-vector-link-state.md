# रूटिंग — डिस्टेंस वेक्टर/लिंक स्टेट

**स्रोत:** मानक कंप्यूटर-नेटवर्किंग संदर्भ (Routing Algorithms — स्थिर/सार्वभौमिक-तकनीकी-ज्ञान)

## 1. रूटिंग की परिभाषा

- **रूटिंग — नेटवर्क में डेटा-पैकेट को स्रोत से गंतव्य तक पहुँचाने हेतु सर्वोत्तम-मार्ग (path) चुनने की प्रक्रिया — राउटर (checklist-फ़ाइल-01/बिंदु-15 "नेटवर्किंग-टर्मिनोलॉजी" से सम्बद्ध) इस निर्णय हेतु उत्तरदायी-डिवाइस।**
- **राउटिंग-प्रोटोकॉल के 2 मुख्य-वर्ग — डिस्टेंस-वेक्टर एवं लिंक-स्टेट।**

## 2. डिस्टेंस वेक्टर (Distance Vector) रूटिंग — अत्यंत उच्च-प्राथमिकता

- **सिद्धांत — प्रत्येक राउटर केवल अपने **प्रत्यक्ष-पड़ोसी (direct neighbours)** से "दूरी" (सामान्यतः हॉप-गणना/hop count) की जानकारी साझा करता है — पूरे-नेटवर्क का सम्पूर्ण-मानचित्र किसी-एक राउटर के पास नहीं होता, केवल "पड़ोसी से सुनी-सुनाई" (rumor-based) जानकारी होती है — इसे **"अफ़वाह-आधारित रूटिंग" (routing by rumor)** भी कहा जाता है।**
- **एल्गोरिदम — Bellman-Ford एल्गोरिदम पर आधारित।**
- **उदाहरण-प्रोटोकॉल — RIP (Routing Information Protocol)।**
- **सीमा — "काउंट-टू-इन्फ़िनिटी (Count-to-Infinity)" समस्या — नेटवर्क-परिवर्तन (topology change) की जानकारी धीरे-धीरे, चरणबद्ध-रूप से फैलती है, जिससे अस्थायी-रूटिंग-लूप बन सकते हैं।**

## 3. लिंक स्टेट (Link State) रूटिंग — अत्यंत उच्च-प्राथमिकता

- **सिद्धांत — प्रत्येक राउटर अपने पड़ोसियों की जानकारी को **सम्पूर्ण-नेटवर्क में सभी-अन्य-राउटरों तक "फ़्लड" (flood)** करता है — परिणाम-स्वरूप, प्रत्येक राउटर के पास सम्पूर्ण-नेटवर्क-टोपोलॉजी का पूर्ण-मानचित्र होता है।**
- **एल्गोरिदम — Dijkstra का "सबसे-छोटा-मार्ग (Shortest Path First/SPF)" एल्गोरिदम — प्रत्येक-राउटर स्वयं अपने पूर्ण-मानचित्र से सर्वोत्तम-मार्ग की गणना करता है।**
- **उदाहरण-प्रोटोकॉल — OSPF (Open Shortest Path First)।**

## 4. डिस्टेंस वेक्टर बनाम लिंक स्टेट — तुलनात्मक-तालिका (MCQ-योग्य)

| आधार | डिस्टेंस वेक्टर | लिंक स्टेट |
|---|---|---|
| **जानकारी-साझाकरण** | केवल प्रत्यक्ष-पड़ोसी को | पूरे-नेटवर्क में फ़्लड |
| **नेटवर्क-दृश्यता** | आंशिक (केवल पड़ोसी-दूरी) | पूर्ण (सम्पूर्ण-टोपोलॉजी) |
| **एल्गोरिदम** | Bellman-Ford | Dijkstra (SPF) |
| **अभिसरण-गति (convergence)** | धीमी | तेज़ |
| **उदाहरण** | RIP | OSPF |
| **संसाधन-उपयोग** | कम (सरल छोटे-नेटवर्क हेतु) | अधिक (जटिल बड़े-नेटवर्क हेतु उपयुक्त) |

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **डिस्टेंस वेक्टर — केवल-पड़ोसी-जानकारी("अफ़वाह-आधारित"), Bellman-Ford, RIP, धीमी-अभिसरण, "Count-to-Infinity" समस्या**।
- **लिंक स्टेट — पूर्ण-नेटवर्क-फ़्लडिंग, Dijkstra-SPF, OSPF, तेज़-अभिसरण, पूर्ण-टोपोलॉजी-दृश्यता**।

## 6. स्वयं-परीक्षण हेतु प्रश्न

1. डिस्टेंस वेक्टर एवं लिंक स्टेट रूटिंग में मूल-अंतर क्या है?
2. "Count-to-Infinity" समस्या किस रूटिंग-प्रकार में होती है?
3. RIP एवं OSPF में से कौन-सा किस रूटिंग-प्रकार का उदाहरण है?
