# IP एड्रेसिंग — IPv4/IPv6 — सबनेटिंग

**स्रोत:** NCERT कक्षा-XII कंप्यूटर विज्ञान (IP Addressing — स्थिर/सार्वभौमिक-तकनीकी-ज्ञान)

## 1. IP एड्रेस — परिभाषा

- **IP (Internet Protocol) एड्रेस — नेटवर्क पर किसी डिवाइस की अद्वितीय, तार्किक-पहचान (checklist-फ़ाइल-01/बिंदु-1 बाइनरी-आधार से सम्बद्ध — IP-एड्रेस भी अंततः बाइनरी-संख्या ही है)।**

## 2. IPv4 — संरचना (अत्यंत उच्च-प्राथमिकता, MCQ-योग्य)

- **IPv4 — 32-बिट-एड्रेस, 4 "ऑक्टेट" (प्रत्येक 8-बिट) में विभाजित, दशमलव-बिंदु-संकेतन (dotted-decimal notation) में लिखा जाता है — उदा. 192.168.1.1।**
- **कुल-सम्भव-एड्रेस — 2³² ≈ 4.29 अरब** — इंटरनेट के तीव्र-विस्तार के कारण यह संख्या **अपर्याप्त** सिद्ध हुई (IPv4-क्षय/exhaustion की समस्या) — यही IPv6 की आवश्यकता का मूल-कारण है।
- **IP-एड्रेस-क्लास (ऐतिहासिक-वर्गीकरण)** — Class A (बड़े-नेटवर्क), Class B (मध्यम), Class C (छोटे-नेटवर्क), Class D (मल्टीकास्ट), Class E (प्रायोगिक)।

## 3. IPv6 — समाधान (अत्यंत उच्च-प्राथमिकता)

- **IPv6 — 128-बिट-एड्रेस, हेक्साडेसिमल-संकेतन (checklist-फ़ाइल-01/बिंदु-1 से सम्बद्ध) में, कोलन (:) से पृथक 8-समूह — उदा. 2001:0db8:85a3:0000:0000:8a2e:0370:7334।**
- **कुल-सम्भव-एड्रेस — 2¹²⁸ ≈ 3.4×10³⁸ — व्यावहारिक-रूप से "असीमित", भविष्य के IoT-विस्तार (checklist-फ़ाइल-02/बिंदु-14) हेतु भी पर्याप्त।**
- **IPv4 बनाम IPv6 — मुख्य-भेद-तालिका:**

| आधार | IPv4 | IPv6 |
|---|---|---|
| बिट-लंबाई | 32-बिट | 128-बिट |
| संकेतन | दशमलव (192.168.1.1) | हेक्साडेसिमल (2001:...) |
| कुल-एड्रेस | ~4.29 अरब | ~3.4×10³⁸ |
| हेडर | जटिल | सरलीकृत (तेज़-रूटिंग) |

## 4. सबनेटिंग (Subnetting) — नेटवर्क-विभाजन-तकनीक

- **सबनेटिंग — किसी बड़े-नेटवर्क को छोटे, तार्किक-रूप से पृथक उप-नेटवर्कों ("सबनेट") में विभाजित करना — checklist-फ़ाइल-03/बिंदु-11 "नेटवर्क-सेगमेंटेशन" का ही तकनीकी-कार्यान्वयन-साधन।**
- **सबनेट मास्क (Subnet Mask)** — यह निर्धारित करता है कि IP-एड्रेस का कौन-सा भाग "नेटवर्क-ID" है एवं कौन-सा भाग "होस्ट-ID" है — उदा. 255.255.255.0 (सामान्य Class-C सबनेट-मास्क)।
- **CIDR (Classless Inter-Domain Routing) संकेतन** — "/n" प्रारूप (उदा. 192.168.1.0/24) — पुरानी-कठोर-क्लास-प्रणाली के स्थान पर लचीला-नेटवर्क-आकार-निर्धारण।
- **लाभ — कुशल-IP-एड्रेस-आवंटन, ट्रैफ़िक-प्रबंधन, सुरक्षा (सबनेट के बीच फ़ायरवॉल-नियम लागू करना)।**

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **IPv4 — 32-बिट, दशमलव, ~4.29-अरब-एड्रेस, अब अपर्याप्त**; **IPv6 — 128-बिट, हेक्साडेसिमल, ~3.4×10³⁸-एड्रेस, व्यावहारिक-रूप-से-असीमित**।
- **सबनेटिंग — बड़े-नेटवर्क का छोटे-सबनेट में विभाजन; सबनेट-मास्क नेटवर्क-बनाम-होस्ट-ID निर्धारित करता है; CIDR = "/n" लचीला-संकेतन**।
