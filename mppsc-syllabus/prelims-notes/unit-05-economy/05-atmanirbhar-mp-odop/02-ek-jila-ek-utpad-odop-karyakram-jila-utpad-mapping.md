# एक जिला एक उत्पाद (ODOP) कार्यक्रम — जिला-उत्पाद मैपिंग

**स्रोत:** Invest MP ODOP Brochure/mptradeportal.org, वेब-सत्यापित — MPPSC/MPSI अत्यंत उच्च-प्राथमिकता (ज़िला-उत्पाद-मैपिंग क्लासिक-MCQ)

## 1. ODOP — राष्ट्रीय-अवधारणा — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **ODOP — **वाणिज्य-उद्योग-मंत्रालय-अंतर्गत DPIIT** द्वारा संचालित — प्रत्येक-ज़िले से **कम-से-कम-1-उत्पाद चुनना/ब्रांडिंग-करना/प्रोत्साहित-करना** — समग्र-सामाजिक-आर्थिक-विकास+संतुलित-क्षेत्रीय-विकास हेतु।**
- **राष्ट्रीय-स्तर — कुल **1,241 उत्पाद, 777 ज़िलों** से चिह्नित।**

## 2. MP — ज़िला-उत्पाद-मैपिंग — उदाहरण — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

| ज़िला | ODOP-उत्पाद |
|---|---|
| **इंदौर** | आलू (Potato) |
| **अशोकनगर (चंदेरी-क्षेत्र)** | चंदेरी-हथकरघा (GI-2005, checklist-Unit-1/file-05-बिंदु-35-क्रॉस-रेफ) |
| **धार** | बाघ-प्रिंट (GI-टैग, checklist-Unit-1/file-05-बिंदु-37-क्रॉस-रेफ) |
| **जबलपुर** | मटर (Peas) / औषधीय-पौधे-प्रसंस्करण (शतावरी/अश्वगंधा) |
| **भोपाल** | ज़री-ज़रदोज़ी एवं जूट-उत्पाद (भोपाल-बटुआ) |

## 3. उद्देश्य — स्थानीय-कौशल-संरक्षण — MCQ-योग्य

- **लक्ष्य — स्थानीय-शिल्प/कौशल का **संरक्षण+विकास** + **स्वदेशी-ज्ञान का प्रोत्साहन**।**

## 4. MP-नीति-स्थिति — MCQ-योग्य

- **⚠️ 2023-24 तक — MP-ODOP-नीति **मसौदा/अधिसूचना-चरण** में थी — सक्रिय-क्रियान्वयन-प्रगति-पर।**
- **आधिकारिक-मंच — **MP Trade Portal (mptradeportal.org/ODOP)** — निर्यात-अवसर/ODOP-उत्पाद/MSME-सहायता/व्यापार-नीतियाँ/प्रोत्साहन/वैश्विक-बाज़ार-पहुँच।**

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **ODOP — DPIIT-संचालित; राष्ट्रीय-1,241-उत्पाद/777-ज़िले**।
- **MP-उदाहरण — इंदौर(आलू)/अशोकनगर(चंदेरी)/धार(बाघ-प्रिंट)/जबलपुर(मटर/औषधीय-पौधे)/भोपाल(ज़री-ज़रदोज़ी)**।
- **MP-नीति — मसौदा/अधिसूचना-चरण(2023-24); MP-Trade-Portal-आधिकारिक-मंच**।
