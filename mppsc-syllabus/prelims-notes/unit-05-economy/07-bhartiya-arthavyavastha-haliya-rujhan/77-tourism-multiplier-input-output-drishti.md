# Tourism Multiplier — इनपुट-आउटपुट दृष्टि

**स्रोत:** checklist-बिंदु-76-से-क्रॉस-रेफ, वेब-सत्यापित — MPPSC/MPSI अत्यंत उच्च-प्राथमिकता (गुणक-प्रभाव-आतिथ्य-परिवहन-शिल्प क्लासिक-MCQ)

## 1. checklist-बिंदु-76 से संबंध — क्रॉस-रेफ

- **पर्यटन-GDP/रोज़गार-आँकड़े checklist-बिंदु-76 में कवर। यहाँ — **मल्टीप्लायर (गुणक)-सिद्धांत** पर गहराई — पर्यटन "बढ़ता-वृद्धि-गुणक" क्यों माना जाता है।**

## 2. टूरिज्म-मल्टीप्लायर — सिद्धांत — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **पर्यटक-व्यय — केवल-होटल/परिवहन तक सीमित नहीं — इसका **प्रत्यक्ष+अप्रत्यक्ष+प्रेरित (induced) प्रभाव** — अन्य-क्षेत्रों (आतिथ्य/परिवहन/हस्तशिल्प/छोटे-व्यवसाय/कृषि-आपूर्ति) में भी आय-रोज़गार-सृजन — checklist-बिंदु-76 का "सशक्त-गुणक-प्रभाव"।**
- **इनपुट-आउटपुट-दृष्टि — पर्यटन-व्यय का **एक-रुपया** — अर्थव्यवस्था में कई-बार-चक्रित होकर **कई-गुना-अंतिम-प्रभाव** उत्पन्न करता है — इसीलिए पर्यटन को "बढ़ता-वृद्धि-गुणक" (growth multiplier) कहा जाता है।**

## 3. हस्तशिल्प-कड़ी — MCQ-योग्य

- **पर्यटन — checklist-Unit-1-हस्तशिल्प-GI-टैग-नोट्स (चंदेरी/महेश्वरी/बाघ-प्रिंट) से सीधा-जुड़ाव — पर्यटन-मांग स्थानीय-शिल्प-अर्थव्यवस्था को सीधा-बाज़ार-लिंकेज देती है।**

## 4. परीक्षा-केंद्रित सार (Quick Revision)

- **टूरिज्म-मल्टीप्लायर — प्रत्यक्ष+अप्रत्यक्ष+प्रेरित-प्रभाव; आतिथ्य-परिवहन-शिल्प-कृषि-आपूर्ति तक विस्तार**।
- **इनपुट-आउटपुट — एक-रुपया-व्यय-कई-गुना-अंतिम-प्रभाव → "बढ़ता-वृद्धि-गुणक"**।
