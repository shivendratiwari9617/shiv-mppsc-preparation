# डेटा अर्थव्यवस्था — ओपन डेटा/गोपनीयता

**स्रोत:** MeitY/checklist-Unit-9-से-क्रॉस-रेफ, वेब-सत्यापित — MPPSC/MPSI अत्यंत उच्च-प्राथमिकता (DPDP-नियम2025-18माह-चरणबद्ध क्लासिक-MCQ)

## 1. checklist-Unit-9/file-03/बिंदु-14 से संबंध — क्रॉस-रेफ

- **DPDP-अधिनियम2023 की मूल-संरचना checklist-Unit-9/file-03-बिंदु-14 (गोपनीयता) में कवर। यहाँ — 2025-नियम+डेटा-अर्थव्यवस्था-आयाम पर।**

## 2. ⚠️ DPDP-नियम-2025 — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **⚠️ DPDP-नियम-2025 — **18-महीने की चरणबद्ध-अनुपालन-समयसीमा**, मुख्य-प्रावधान **12-18 महीनों** में लागू — व्यक्तिगत-डेटा-प्रबंधन+गोपनीयता-अधिकार+संगठनात्मक-जवाबदेही हेतु "नागरिक-केंद्रित-प्रणाली"।**

## 3. डेटा-अर्थव्यवस्था — दोहरा-आयाम — MCQ-योग्य

- **ओपन-डेटा (checklist-Unit-9/file-04-बिंदु-3-NDSAP) — सरकारी-डेटा-सार्वजनिक-उपयोग — नवाचार-प्रोत्साहन।**
- **⚠️ ओपन-डेटा-बनाम-गोपनीयता — सीधा-तनाव (tension) — अधिक-खुलापन=अधिक-नवाचार-अवसर, किंतु अधिक-गोपनीयता-जोखिम — DPDP-अधिनियम यही संतुलन-बनाने का प्रयास।**

## 4. भरोसेमंद-वातावरण — स्टार्टअप-MSME-लाभ — MCQ-योग्य

- **DPDP-नियम+RBI-डिजिटल-लेंडिंग-दिशा-निर्देश-2025 (checklist-आगामी-बिंदु-121) — स्टार्टअप्स+MSME+डिजिटल-सेवाओं-हेतु **भरोसेमंद-वातावरण** — डेटा-सुरक्षा-नियामक-स्पष्टता से निवेशक-विश्वास-वृद्धि।**

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **⚠️DPDP-नियम2025 — 18माह-चरणबद्ध-अनुपालन; नागरिक-केंद्रित-गोपनीयता-प्रणाली**।
- **ओपन-डेटा-बनाम-गोपनीयता — नवाचार-बनाम-जोखिम-संतुलन-तनाव**।
- **DPDP+RBI-डिजिटल-लेंडिंग-दिशा-निर्देश — स्टार्टअप-MSME-भरोसेमंद-वातावरण**।
