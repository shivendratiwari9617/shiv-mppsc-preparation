# व्यापार चक्र — बूम-मंदी-रिकवरी

**स्रोत:** NCERT कक्षा-XII अर्थशास्त्र (मैक्रोइकॉनॉमिक्स), स्थिर-अवधारणा — MPPSC/MPESB अत्यंत उच्च-प्राथमिकता (4-चरण-चक्र क्लासिक-MCQ)

## 1. व्यापार-चक्र — 4-चरण — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

| चरण | विशेषता |
|---|---|
| **1. विस्तार/उछाल (Boom/Expansion)** | उच्च-उत्पादन/रोज़गार/उपभोग; कीमतें बढ़ती हैं |
| **2. शिखर (Peak)** | अधिकतम-आर्थिक-गतिविधि — मुद्रास्फीति-दबाव-चरम |
| **3. संकुचन/मंदी (Recession/Contraction)** | उत्पादन/रोज़गार-गिरावट; **लगातार-2-तिमाही ऋणात्मक-GDP-वृद्धि = तकनीकी-मंदी** |
| **4. गर्त/निम्न-बिंदु (Trough) → पुनर्प्राप्ति (Recovery)** | न्यूनतम-आर्थिक-गतिविधि से पुनः-विस्तार-की-ओर |

## 2. मंदी-बनाम-अवसाद — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **मंदी (Recession)** — अल्पकालिक/मध्यम-आर्थिक-गिरावट।
- **अवसाद (Depression)** — **दीर्घकालिक/गंभीर मंदी** — जैसे **1930 का महामंदी (Great Depression)**।

## 3. सरकारी-हस्तक्षेप — प्रति-चक्रीय-नीति — MCQ-योग्य

- **मंदी-काल — विस्तारवादी (expansionary) राजकोषीय+मौद्रिक-नीति (कर-कटौती/व्यय-वृद्धि/रेपो-दर-कटौती)।**
- **उछाल-काल (अति-गर्म-अर्थव्यवस्था) — संकुचनकारी (contractionary) नीति (कर-वृद्धि/रेपो-दर-वृद्धि) — मुद्रास्फीति-नियंत्रण-हेतु।**

## 4. परीक्षा-केंद्रित सार (Quick Revision)

- **4-चरण — विस्तार/बूम→शिखर→संकुचन/मंदी→गर्त→पुनर्प्राप्ति**।
- **तकनीकी-मंदी — लगातार-2-तिमाही-ऋणात्मक-GDP-वृद्धि**।
- **मंदी(अल्पकालिक) बनाम अवसाद(दीर्घकालिक-गंभीर, जैसे1930-महामंदी)**।
- **प्रति-चक्रीय-नीति — मंदी-में-विस्तारवादी, उछाल-में-संकुचनकारी**।

## 5. स्वयं-परीक्षण हेतु प्रश्न

1. व्यापार-चक्र के 4 चरण क्या हैं?
2. तकनीकी-मंदी की परिभाषा क्या है?
3. मंदी एवं अवसाद में क्या अंतर है?
