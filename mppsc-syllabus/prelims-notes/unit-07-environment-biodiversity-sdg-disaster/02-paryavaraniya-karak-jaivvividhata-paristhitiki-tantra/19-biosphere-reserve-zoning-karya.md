# बायोस्फीयर रिज़र्व — ज़ोनिंग/कार्य

**स्रोत:** UNESCO-MAB कार्यक्रम, वेब-सत्यापित — MPPSC/MPESB अत्यंत उच्च-प्राथमिकता (3-ज़ोन-संरचना क्लासिक-MCQ)

## 1. UNESCO-MAB — कार्यक्रम — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **बायोस्फीयर-रिज़र्व — **UNESCO मानव-एवं-जीवमंडल (Man and the Biosphere/MAB) कार्यक्रम** के अंतर्गत नामित।**

## 2. 3-ज़ोन-संरचना — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

| ज़ोन | कार्य |
|---|---|
| **कोर-ज़ोन (Core)** | सबसे-भीतरी, **कठोर-संरक्षण**, न्यूनतम-मानव-हस्तक्षेप — केवल-संरक्षण-उद्देश्य |
| **बफ़र-ज़ोन (Buffer)** | कोर-को-घेरे-हुए — सीमित-गतिविधि (शोध/शिक्षा/सतत-संसाधन-प्रबंधन) अनुमत्य |
| **संक्रमण-ज़ोन (Transition)** | बाह्यतम — समुदाय-निवास + प्रबंधन-सहयोग-से सतत-आर्थिक-गतिविधि |

## 3. भारत — वर्तमान-संख्या — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **भारत — कुल **18 बायोस्फीयर-रिज़र्व (2025)** — कुल-क्षेत्रफल **~91,425 वर्ग-किमी**।**
- **इनमें-से **13 UNESCO-MAB-अंतर्गत मान्यता-प्राप्त**।**
- **सितंबर 2025 — **कोल्ड डेज़र्ट बायोस्फीयर-रिज़र्व (हिमाचल प्रदेश)** — **13वाँ UNESCO-नामित** (~7,770 वर्ग-किमी UNESCO-क्षेत्र) — 37वें MAB-अंतर्राष्ट्रीय-समन्वय-परिषद-सत्र में।**

## 4. परीक्षा-केंद्रित सार (Quick Revision)

- **बायोस्फीयर-रिज़र्व — UNESCO-MAB-कार्यक्रम-अंतर्गत; 3-ज़ोन — कोर(कठोर-संरक्षण)/बफ़र(सीमित-गतिविधि)/संक्रमण(समुदाय-निवास)**।
- **भारत — 18-बायोस्फीयर-रिज़र्व, ~91,425वर्गkm; 13-UNESCO-मान्यता-प्राप्त**।
- **सितंबर2025 — कोल्ड-डेज़र्ट(HP) — 13वाँ-UNESCO-नामित**।
