# चक्रवात — श्रेणी/तूफानी लहर (Storm Surge)/तटीय तैयारी

**स्रोत:** IMD-चक्रवात-SOP, वेब-सत्यापित — MPPSC/MPESB अत्यंत उच्च-प्राथमिकता (IMD-6-श्रेणी-गति-आधार क्लासिक-MCQ)

## 1. IMD — चक्रवात-वर्गीकरण — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **भारत मौसम-विज्ञान-विभाग (IMD) — बंगाल-की-खाड़ी/अरब-सागर के निम्न-दाब-प्रणालियों को **6 श्रेणियों** में वर्गीकृत करता है — विश्व-मौसम-संगठन (WMO) द्वारा अपनाया-गया-मानदंड — **3-मिनट-औसत-अधिकतम-निरंतर-पवन-गति** पर आधारित:**

| श्रेणी | पवन-गति |
|---|---|
| **डिप्रेशन (Depression)** | <60 km/hr |
| **चक्रवाती-तूफ़ान (Cyclonic Storm)** | 65-89 km/hr |
| **गंभीर-चक्रवाती-तूफ़ान (Severe Cyclonic Storm)** | 89-117 km/hr |
| **अत्यंत-गंभीर-चक्रवाती-तूफ़ान (Very Severe Cyclonic Storm)** | 119-165 km/hr |
| **अतिशय-गंभीर-चक्रवाती-तूफ़ान (Extremely Severe Cyclonic Storm)** | — (दूसरा-उच्चतम-वर्गीकरण) |
| **सुपर-साइक्लोनिक-तूफ़ान (Super Cyclonic Storm)** | ≥220 km/hr |

## 2. तूफानी-लहर (Storm Surge) — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **तूफानी-लहर — सामान्य-भविष्यवाणी-की-गई खगोलीय-ज्वार-स्तर-से **ऊपर समुद्र-स्तर-वृद्धि** — तटीय-सड़कें/स्थान बाढ़/तरंग-रन-अप से क्षति-के-प्रति भेद्य।**

## 3. checklist-क्रॉस-रेफ

- **checklist-Unit-7/file-02/बिंदु-25 (मैंग्रोव/ब्लू-कार्बन) — मैंग्रोव तूफानी-लहर-ऊँचाई 50-70%-तक-कम-करते हैं।**

## 4. परीक्षा-केंद्रित सार (Quick Revision)

- **IMD-6-श्रेणी — डिप्रेशन(<60)→चक्रवाती-तूफ़ान(65-89)→गंभीर(89-117)→अत्यंत-गंभीर(119-165)→अतिशय-गंभीर→सुपर-साइक्लोनिक(≥220 km/hr)**।
- **तूफानी-लहर — सामान्य-ज्वार-से-अधिक समुद्र-स्तर-वृद्धि; मैंग्रोव-न्यूनीकरण-भूमिका**।
