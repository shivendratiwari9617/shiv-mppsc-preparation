# घटना कमान प्रणाली (Incident Command System, ICS)

**स्रोत:** NDMA-दिशा-निर्देश, वेब-सत्यापित — MPPSC/MPESB अत्यंत उच्च-प्राथमिकता (भारत में "IRS" नामकरण MCQ-योग्य)

## 1. checklist-बिंदु-27 से संबंध — क्रॉस-रेफ

- **NDMA द्वारा **जुलाई 2010** DM-अधिनियम-2005-धारा-6-अंतर्गत जारी दिशा-निर्देश — भारत में ICS को **"घटना अनुक्रिया प्रणाली (Incident Response System/IRS)"** नाम से क्रियान्वित।**

## 2. ICS/IRS — अवधारणा — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **ICS — प्रबंधन-उपकरण — नागरिक-संगठन को **अस्थायी-संगठन-संरचना** स्थापित करने की गुंजाइश देता है — आपातकालीन-अनुक्रिया-संचालन को सुचारू-रूप-से क्रियान्वित करने हेतु।**
- **जटिलता-स्तर-निरपेक्ष सभी-कार्यों को सम्मिलित — विभिन्न-अनुभागों-सहित संयुक्त-टीम की परिकल्पना — सभी-संभावित-अनुक्रिया-आवश्यकताओं की पूर्ति।**

## 3. उद्देश्य — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **ICS — आपातकाल के दौरान प्रभावी-निर्णय-निर्धारण हेतु स्पष्ट-भूमिकाएँ/उत्तरदायित्व/प्रक्रियाएँ स्थापित करता है।**

## 4. संरचना — क्रियान्वयन — MCQ-योग्य

- **उत्तरदायी-अधिकारी (Responsible Officer) — घटना-कमांडर (IC) को उत्तरदायित्व सौंप सकता है — IC, घटना-अनुक्रिया-टीमों (IRTs) के माध्यम से घटना प्रबंधित करता है।**
- **IRTs — सभी-स्तरों पर **पूर्व-निर्धारित** — राज्य/ज़िला/उप-प्रभाग/तहसील-ब्लॉक।**

## 5. DM-अधिनियम-ढाँचे से एकीकरण — checklist-बिंदु-27 क्रॉस-रेफ — MCQ-योग्य

- **DM-अधिनियम-2005 — राष्ट्रीय/राज्य/ज़िला-स्तरीय-प्राधिकरण (NDMA/SDMA/DDMA) स्थापित करता है, किंतु घटना के दौरान **परिचालनात्मक-नियंत्रण अक्सर खंडित** रहता है — ICS/IRS का एकीकरण इस-अंतराल को पाटने हेतु आवश्यक।**

## 6. परीक्षा-केंद्रित सार (Quick Revision)

- **ICS — भारत में "IRS"-नामकरण; NDMA-दिशा-निर्देश-जुलाई2010, DM-अधिनियम-धारा6-अंतर्गत**।
- **उद्देश्य — अस्थायी-संगठन-संरचना, स्पष्ट-भूमिका/उत्तरदायित्व**।
- **संरचना — उत्तरदायी-अधिकारी→घटना-कमांडर(IC)→IRTs(सभी-स्तरों पर पूर्व-निर्धारित)**।
