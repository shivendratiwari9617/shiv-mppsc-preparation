# बाढ़/फ्लैश-फ्लड — जलग्रहण/जल निकासी

**स्रोत:** NDMA-बाढ़-प्रबंधन-दिशा-निर्देश, वेब-सत्यापित — MPPSC/MPESB अत्यंत उच्च-प्राथमिकता (शहरी-बाढ़-पृथक्करण-निर्णय MCQ-योग्य)

## 1. बाढ़-प्रकार — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

| प्रकार | विशेषता |
|---|---|
| **नदी-बाढ़ (Fluvial)** | नदी-बाढ़-मैदान में, प्रवाह चैनल-क्षमता-से-अधिक→तटों-पर-फैलाव |
| **फ़्लैश-फ़्लड (Flash Flood)** | अल्पकालिक-तीव्र-संवहन-तूफ़ान, छोटे-क्षेत्र पर — **पर्वतीय-क्षेत्रों में अधिक-बार** (बार-बार-गरज-तूफ़ान से) |
| **शहरी-बाढ़ (Urban Flooding)** | तीव्र-वर्षा से तेज़-अपवाह — तूफ़ान-जल-निकासी-प्रणाली-क्षमता-से-अधिक |
| **तटीय-बाढ़ (Coastal)** | तूफानी-लहर+तेज़-हवा उच्च-ज्वार से मेल |

## 2. मुख्य-कारण — MCQ-योग्य

- **तीव्र-वर्षा/नदी-अतिप्रवाह/चक्रवात/तूफानी-लहर/क्लाउडबर्स्ट/GLOF (checklist-बिंदु-47 क्रॉस-रेफ)/बाँध-विफलता/खराब-जल-निकासी/अनियोजित-शहरीकरण।**
- **चक्रवात/चक्रवाती-परिसंचरण/क्लाउडबर्स्ट — फ़्लैश-फ़्लड का कारण, भारी-हानि।**

## 3. NDMA — शहरी-बाढ़ — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **NDMA — **शहरी-बाढ़ को पहली-बार सामान्य-बाढ़-से पृथक-कर एक-स्वतंत्र-आपदा-रूप-में संबोधित** करने का निर्णय — सामान्य-नदी-बाढ़-दिशा-निर्देशों-से-भिन्न-दृष्टिकोण आवश्यक।**

## 4. जलग्रहण/जल-निकासी-समस्या — MCQ-योग्य

- **पंजाब/हरियाणा — बाढ़ मुख्यतः **अपर्याप्त-जल-निकासी**+नदियों की अपर्याप्त-वहन-क्षमता से — जल-निकासी-कंजेशन+नदी-तट-अपरदन।**

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **बाढ़-4-प्रकार — नदी(fluvial)/फ़्लैश/शहरी/तटीय**।
- **NDMA — शहरी-बाढ़-को-सामान्य-बाढ़-से-पृथक-स्वतंत्र-आपदा-मान्यता**।
- **पंजाब-हरियाणा — जल-निकासी-अपर्याप्तता प्रमुख-कारण**।
