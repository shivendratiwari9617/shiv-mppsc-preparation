# अनुकूलन बनाम शमन (Adaptation vs Mitigation) — रणनीतियाँ

**स्रोत:** IPCC-AR5/DST-भारत, वेब-सत्यापित — MPPSC/MPSI अत्यंत उच्च-प्राथमिकता (NAPCC-8-मिशन क्लासिक-MCQ)

## 1. मूल-परिभाषा — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **शमन (Mitigation) — IPCC-परिभाषा: **"ग्रीनहाउस-गैस-स्रोतों को कम-करने या सिंक को बढ़ाने हेतु मानवीय-हस्तक्षेप"** — **मूल-कारण को संबोधित करना**।**
- **अनुकूलन (Adaptation) — वास्तविक/अपेक्षित-जलवायु+इसके-प्रभावों के अनुरूप समायोजन-प्रक्रिया — सामाजिक/आर्थिक/पर्यावरणीय-प्रथाओं में परिवर्तन — क्षति-न्यूनीकरण।**
- **सरल-उपमा — अनुकूलन = "डूबती-नाव से पानी-निकालना" (तात्कालिक-प्रभाव-प्रबंधन) बनाम शमन = "रिसाव-सील-करना" (मूल-समस्या-समाधान)।**

## 2. उदाहरण — MCQ-योग्य

| श्रेणी | उदाहरण |
|---|---|
| **अनुकूलन** | बाढ़-सुरक्षा-निर्माण, सूखा-प्रतिरोधी-फ़सल-विकास, जल-प्रबंधन-सुधार, प्रारंभिक-चेतावनी-प्रणाली |
| **शमन** | जीवाश्म-ईंधन(कोयला/तेल/गैस)-को-नवीकरणीय-ऊर्जा(सौर/पवन/भू-तापीय)-से प्रतिस्थापन |

- **IPCC — कोई-भी-एक-विकल्प-अकेले-पर्याप्त-नहीं; प्रभावी-क्रियान्वयन सभी-स्तरों पर नीति+सहयोग पर निर्भर — अनुकूलन-शमन-एकीकृत-प्रतिक्रिया से सुदृढ़ता।**

## 3. भारत — राष्ट्रीय जलवायु परिवर्तन कार्य-योजना (NAPCC) — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **NAPCC — **30 जून 2008** शुभारंभ — **8 राष्ट्रीय-मिशन**, प्रत्येक-शमन/अनुकूलन के विशिष्ट-पहलू को लक्षित करते हुए विकास-प्राथमिकताओं पर भी फ़ोकस:**

| क्र. | मिशन |
|---|---|
| 1 | राष्ट्रीय सौर मिशन |
| 2 | उन्नत-ऊर्जा-दक्षता हेतु राष्ट्रीय मिशन |
| 3 | सतत-पर्यावास हेतु राष्ट्रीय मिशन |
| 4 | राष्ट्रीय जल मिशन |
| 5 | हिमालयी-पारितंत्र-संधारण हेतु राष्ट्रीय मिशन |
| 6 | हरित भारत हेतु राष्ट्रीय मिशन |
| 7 | सतत-कृषि हेतु राष्ट्रीय मिशन (checklist-बिंदु-15 CSA क्रॉस-रेफ) |
| 8 | जलवायु-परिवर्तन हेतु सामरिक-ज्ञान पर राष्ट्रीय मिशन |

- **NAPCC-मिशन शमन-फ़ोकस (सौर/ऊर्जा-दक्षता) एवं अनुकूलन-फ़ोकस (जल/हिमालयी-पारितंत्र/कृषि) दोनों का मिश्रण।**

## 4. परीक्षा-केंद्रित सार (Quick Revision)

- **शमन=स्रोत-कमी/सिंक-वृद्धि(मूल-कारण); अनुकूलन=प्रभाव-समायोजन(तात्कालिक-प्रबंधन)**।
- **NAPCC — 30जून2008, 8-मिशन(सौर/ऊर्जा-दक्षता/पर्यावास/जल/हिमालयी-पारितंत्र/हरित-भारत/सतत-कृषि/सामरिक-ज्ञान)**।
