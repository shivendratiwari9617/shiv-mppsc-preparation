# पाचन तंत्र — अंग एवं कार्य

**स्रोत:** NCERT कक्षा-XI जीव विज्ञान अध्याय 16 "पाचन एवं अवशोषण" (Digestion and Absorption), वेब-सत्यापित — MPPSC/MPSI सामान्य-विज्ञान-अनुभाग हेतु अत्यंत-उच्च-प्राथमिकता (हर वर्ष प्रश्न आते हैं)

## 1. आहार-नाल (Alimentary Canal) — क्रम — अत्यंत उच्च-प्राथमिकता, MCQ-योग्य

- **क्रम — मुख (Mouth) → ग्रसनी (Pharynx) → ग्रासनली/भोजन-नली (Oesophagus) → आमाशय (Stomach) → छोटी-आंत (Small Intestine — ग्रहणी/Duodenum→जेजुनम/Jejunum→इलियम/Ileum) → बड़ी-आंत (Large Intestine — सीकम/Caecum→कोलन/Colon→मलाशय/Rectum) → गुदा (Anus)।**
- **कुल-लम्बाई — वयस्क-मानव-आहार-नाल ~8-9 मीटर; छोटी-आंत सबसे-लम्बी (~6.5m)।**
- **आमाशय के 3 भाग — कार्डिएक (Cardiac), फ़ंडिक (Fundic), पाइलोरिक (Pyloric)।**

## 2. पाचन-ग्रंथियाँ (Digestive Glands) — MCQ-योग्य

| ग्रंथि | स्थान | प्रमुख-स्राव |
|---|---|---|
| **लार-ग्रंथि (Salivary Gland)** | मुख — 3 जोड़ी (पैरोटिड सबसे-बड़ी/सबमैंडिबुलर/सबलिंगुअल) | लार — एंज़ाइम **टायलिन/सैलाइवरी-एमाइलेज़** (स्टार्च→माल्टोज़) |
| **यकृत (Liver)** | उदर, शरीर की सबसे-बड़ी-ग्रंथि | पित्त (Bile) — वसा-इमल्सीकरण (कोई-एंज़ाइम-नहीं, यकृत में निर्मित/पित्ताशय-में-संग्रहित) |
| **अग्न्याशय (Pancreas)** | आमाशय-के-पीछे — मिश्रित-ग्रंथि (अंतःस्रावी+बहिःस्रावी) | ट्रिप्सिन/एमाइलेज़/लाइपेज़ (पाचक); इंसुलिन/ग्लूकागॉन (अंतःस्रावी — checklist-बिंदु-9 से सम्बद्ध) |
| **आमाशय-ग्रंथि (Gastric Gland)** | आमाशय-भित्ति | पेप्सिन (प्रोटीन-पाचन) + HCl (जीवाणु-नाशक, pH~1.5-3.5) + म्यूकस |
| **आंत्र-ग्रंथि (Intestinal Gland)** | छोटी-आंत | माल्टेज़/लैक्टेज़/सुक्रेज़/इरेप्सिन |

## 3. प्रमुख एंज़ाइम एवं उनके सब्सट्रेट/उत्पाद

| एंज़ाइम | स्रोत | कार्य |
|---|---|---|
| टायलिन (एमाइलेज़) | लार | स्टार्च → माल्टोज़ |
| पेप्सिन | आमाशय | प्रोटीन → पेप्टाइड |
| ट्रिप्सिन | अग्न्याशय | प्रोटीन/पेप्टाइड → अमीनो-अम्ल |
| लाइपेज़ | अग्न्याशय | वसा → वसा-अम्ल+ग्लिसरॉल |
| पित्त-लवण | यकृत (कोई-एंज़ाइम-नहीं) | वसा का इमल्सीकरण (पायसीकरण) |

## 4. अवशोषण एवं MPPSC-प्रासंगिक-रोग

- **पोषक-तत्वों का अधिकतम-अवशोषण — छोटी-आंत (विशेषतः इलियम — आंतरिक-सतह पर **विलाई/Villi** द्वारा सतह-क्षेत्रफल-वृद्धि)।**
- **जल का अधिकतम-अवशोषण — बड़ी-आंत (कोलन)।**
- **यकृत — शरीर की सबसे-बड़ी-ग्रंथि/सबसे-बड़ा-आंतरिक-अंग; पित्त-निर्माण+ग्लाइकोजन-संग्रहण+विषहरण (detoxification)+यूरिया-निर्माण — बहु-कार्यात्मक।**
- **प्रमुख-रोग (MPPSC/MPSI सार्वजनिक-स्वास्थ्य-सन्दर्भ — checklist-फ़ाइल-07 से सम्बद्ध) — पीलिया (Jaundice — बिलीरुबिन-वृद्धि), पेप्टिक-अल्सर (H. pylori-जीवाणु-सम्बद्ध), अतिसार/डायरिया (Diarrhoea)।**

## 5. परीक्षा-केंद्रित सार (Quick Revision)

- **आहार-नाल-क्रम — मुख→ग्रसनी→ग्रासनली→आमाशय→छोटी-आंत(ग्रहणी-जेजुनम-इलियम)→बड़ी-आंत(सीकम-कोलन-मलाशय)→गुदा**।
- **3-प्रमुख-पाचक-ग्रंथियाँ — लार-ग्रंथि(टायलिन)/यकृत(पित्त)/अग्न्याशय(ट्रिप्सिन-लाइपेज़-एमाइलेज़+इंसुलिन-ग्लूकागॉन)**।
- **यकृत=शरीर की सबसे-बड़ी-ग्रंथि; छोटी-आंत=सबसे-लम्बा-भाग+अधिकतम-पोषक-अवशोषण(विलाई); बड़ी-आंत=अधिकतम-जल-अवशोषण**।

## 6. स्वयं-परीक्षण हेतु प्रश्न

1. आहार-नाल का सही-क्रम क्या है?
2. कौन-सी ग्रंथि शरीर की सबसे-बड़ी-ग्रंथि है, और यह कौन-सा पाचक-रस स्रावित करती है?
3. पित्त वसा को कैसे पचाता है, और यह किस अर्थ में "एंज़ाइम नहीं" है?
4. पोषक-तत्वों का अधिकतम-अवशोषण कहाँ होता है, और यह किस संरचना द्वारा सम्भव होता है?
