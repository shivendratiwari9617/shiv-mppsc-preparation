# mppsc-syllabus — Topic Lists (100% Syllabus Coverage Check)

Pure topic listings (no explanatory content) organized against the **official** MPPSC State Service Examination 2026 syllabus (`Syllabus/Exam_Plan_and_Syllabus_State_Service_Examination_2026_Dated_05_01_2026.pdf`). This is a listing/checklist layer only — deep content, if wanted later, is a separate follow-up task, not done here.

## Structure

### `prelims/`
The **complete** official Prelims syllabus (Paper I — General Studies, 10 subject units; Paper II — General Aptitude Test), in Hindi, listing every topic exactly as the official syllabus states it — **not** filtered down to only what's missing from existing content. Unit numbering matches this repo's existing 10 unit folders (which split/merge the official syllabus's own item numbers slightly differently — noted inline in each file, e.g. Geography of India + Geography of MP are merged into repo-Unit 3; Science/Environment/Health is split across repo-Units 6 and 7).

| File | Official syllabus item(s) |
|---|---|
| `unit-01-mp-history-culture-literature.md` | Item 2 |
| `unit-02-india-history.md` | Item 1 |
| `unit-03-india-mp-geography.md` | Items 3 + 4 |
| `unit-04-constitutional-system.md` | Item 5 |
| `unit-05-economy.md` | Item 6 |
| `unit-06-science-technology-public-health.md` | Item 7, bullets 1-7 |
| `unit-07-environment-biodiversity-sdg-disaster.md` | Item 7, bullets 8-10 |
| `unit-08-current-affairs.md` | Item 8 |

A prior, narrower gap-analysis (`gaps/unit1_gaps.md` – `unit10_gaps.md`) already exists separately in the repo root, identifying which specific sub-topics are missing/thin in the existing 1,743-topic content — that is a different, smaller artifact from this full listing and is not duplicated here.

### `mains/`
The complete official Mains syllabus (6 compulsory papers, no optional subject, 1500 marks + 185 interview = 1685 total), transcribed unit-by-unit directly from the official PDF's scanned pages (its embedded text layer is corrupted/unusable — pages were rendered to images and read visually), in Hindi. One file per paper:

| File | Paper | Marks |
|---|---|---|
| `paper-1-history-geography.md` | History (A) + Geography (B) | 300 |
| `paper-2-political-science-sociology.md` | Political Science (A) + Sociology (B) | 300 |
| `paper-3-economics-science-technology-health.md` | Economics (A) + Science/Tech/Public Health (B) | 300 |
| `paper-4-philosophy-psychology-public-admin-entrepreneurship-management.md` | Philosophy/Psychology/Public Admin (A) + Entrepreneurship/Management (B) | 300 |
| `paper-5-general-hindi-grammar.md` | General Hindi & Grammar (mark-scheme based) | 200 |
| `paper-6-hindi-essay-drafting.md` | Hindi Essay & Official Drafting | 100 |

This is entirely new ground — no prior Mains content exists elsewhere in this repo.
