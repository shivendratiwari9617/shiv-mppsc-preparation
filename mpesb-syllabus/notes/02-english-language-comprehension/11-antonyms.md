# Antonyms

**Subject:** English Language Comprehension | **Section:** Vocabulary | **Exam relevance:** MPESB along with MPPSC, Vyapam/ESB, Patwari, MP Police — "choose the antonym/opposite" is tested with the same frequency as synonyms, often from the same vocabulary pool.

---

## 1. What are Antonyms?

Words that have the **opposite meaning** of a given word.

### Two Ways Antonyms Are Formed
1. **A completely different word:** happy ↔ sad
2. **A negating prefix added to the same root** (un-, in-, im-, dis-, non-, mis-, anti- — see point 22, Word formation): honest ↔ dishonest, possible ↔ impossible, agree ↔ disagree

## 3. Strategy — Negating Prefixes (Cross-Reference Point 22)

When a word doesn't have a distinctly different antonym in common use, English often forms the opposite with a **negating prefix**:

| Prefix | Example |
|---|---|
| un- | happy → unhappy |
| in- | correct → incorrect |
| im- (before b/m/p) | possible → impossible |
| dis- | agree → disagree |
| non- | sense → nonsense |
| mis- | understand → misunderstand |
| anti- | social → antisocial |

## 5. Most Important Exam-Focused Points

1. Study this list **alongside point 10 (Synonyms)** — most of these words overlap directly, so learning both directions for the same word roughly doubles retention for the same memorization effort.
2. When a word's antonym isn't a distinct vocabulary word, check whether a **negating prefix (Section 3)** applies — this is a reliable fallback for unfamiliar words in the exam.
3. Watch for **near-synonym distractors** in MCQ options — e.g., for "Abundant," an option like "Sufficient" is a trap (close in meaning, not opposite); the true antonym "Scarce" is what's needed.
