# MS Word — मूल टूलबार, फॉर्मेटिंग, मेल मर्ज, शॉर्टकट कीज़

MS Word एक **वर्ड प्रोसेसिंग (Word Processing)** एप्लीकेशन सॉफ्टवेयर है — Microsoft Office सुइट का भाग। परीक्षाओं में मुख्यतः शॉर्टकट कीज़ व मेन्यू/रिबन में किसी विकल्प का स्थान पूछा जाता है।

## रिबन (Ribbon) के मुख्य टैब

| टैब | मुख्य कार्य |
|---|---|
| **Home** | फॉन्ट, पैराग्राफ फॉर्मेटिंग, स्टाइल, क्लिपबोर्ड (कट/कॉपी/पेस्ट) |
| **Insert** | टेबल, चित्र, हेडर-फुटर, पेज नंबर, हाइपरलिंक, WordArt, शेप |
| **Design** | थीम, पेज रंग, वॉटरमार्क |
| **Layout / Page Layout** | मार्जिन, ओरिएंटेशन (Portrait/Landscape), पेज साइज़, कॉलम |
| **References** | विषय-सूची (Table of Contents), फुटनोट, साइटेशन, इंडेक्स |
| **Mailings** | मेल मर्ज (Mail Merge) |
| **Review** | स्पेल चेक, ग्रामर चेक, ट्रैक चेंजेस, कमेंट |
| **View** | डॉक्यूमेंट व्यू (Print Layout, Web Layout, Read Mode), ज़ूम |

## फॉर्मेटिंग विकल्प (Home टैब)

- **फॉन्ट फॉर्मेटिंग** — फॉन्ट प्रकार, आकार (Size), बोल्ड (Bold), इटैलिक (Italic), अंडरलाइन (Underline), फॉन्ट रंग, हाइलाइट रंग।
- **पैराग्राफ फॉर्मेटिंग** — संरेखण (Align Left/Center/Right/Justify), लाइन स्पेसिंग, बुलेट्स/नंबरिंग, इंडेंट।
- **स्टाइल (Styles)** — पूर्व-निर्धारित फॉर्मेटिंग सेट (Heading 1, Heading 2, Normal आदि) — बड़े दस्तावेज़ों में एकरूपता व स्वचालित विषय-सूची हेतु उपयोगी।

## मेल मर्ज (Mail Merge)

एक ही पत्र/दस्तावेज़ को कई प्राप्तकर्ताओं को व्यक्तिगत विवरण (नाम, पता आदि) के साथ भेजने की सुविधा — सरकारी/कार्यालयीन पत्राचार में अत्यंत उपयोगी (जैसे एक साथ अनेक कर्मचारियों को व्यक्तिगत नियुक्ति-पत्र भेजना)।

**चरण:**
1. मुख्य दस्तावेज़ (Main Document) तैयार करना — जैसे पत्र का प्रारूप।
2. डेटा स्रोत (Data Source) जोड़ना — Excel शीट या Word/Access टेबल जिसमें नाम, पता आदि हों (**Mailings → Select Recipients**)।
3. मर्ज फील्ड डालना (**Insert Merge Field**) — जहाँ नाम/पता स्वतः भरा जाए।
4. मर्ज पूरा करना व प्रिंट/ईमेल करना (**Finish & Merge**)।

## महत्वपूर्ण अतिरिक्त तथ्य

- MS Word की डिफ़ॉल्ट फाइल एक्सटेंशन **.docx** (पुराना संस्करण **.doc**) है।
- **वर्डआर्ट (WordArt)** — सजावटी टेक्स्ट प्रभाव डालने हेतु।
- **हेडर-फुटर (Header-Footer)** — प्रत्येक पेज के ऊपर/नीचे दोहराई जाने वाली सामग्री (जैसे संस्था का नाम, पेज नंबर)।
- Word में **ट्रैक चेंजेस (Track Changes)** सुविधा दस्तावेज़ में किए गए संपादन को चिह्नित रखती है — सहयोगी संपादन (collaborative editing) हेतु उपयोगी।

## अभ्यास प्रश्न

1. एक ही पत्र कई लोगों को व्यक्तिगत विवरण सहित भेजने की सुविधा? — **मेल मर्ज**
2. टेक्स्ट को बोल्ड करने की शॉर्टकट कुंजी? — **Ctrl+B**
3. MS Word की डिफ़ॉल्ट फाइल एक्सटेंशन? — **.docx**

## परीक्षा हेतु सबसे महत्वपूर्ण तथ्य

- Ctrl+B/I/U (बोल्ड/इटैलिक/अंडरलाइन) व Ctrl+C/V/X (कॉपी/पेस्ट/कट) जैसे सार्वभौमिक शॉर्टकट अवश्य रटें (बिंदु 12 में विस्तृत सूची भी देखें)।
- मेल मर्ज की प्रक्रिया (मुख्य दस्तावेज़ + डेटा स्रोत → मर्ज फील्ड → फिनिश) समझें — यह व्यावहारिक कार्यालयीन प्रश्न है।
- .docx एक्सटेंशन व रिबन के मुख्य टैब (Home, Insert, Layout, Mailings, Review) याद रखें।
