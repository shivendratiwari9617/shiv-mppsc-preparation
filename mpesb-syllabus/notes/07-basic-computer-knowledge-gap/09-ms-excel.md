# MS Excel — मूल फंक्शन (SUM, AVERAGE), सेल फॉर्मेटिंग, चार्ट, शॉर्टकट कीज़

MS Excel एक **स्प्रेडशीट (Spreadsheet)** एप्लीकेशन है — डेटा को पंक्ति (Row) व स्तंभ (Column) में व्यवस्थित कर गणना/विश्लेषण करने हेतु।

## मूल संरचना

- **वर्कबुक (Workbook)** — पूरी Excel फाइल (.xlsx)।
- **वर्कशीट (Worksheet)** — वर्कबुक के अंदर एक शीट (टैब); एक वर्कबुक में कई वर्कशीट हो सकती हैं।
- **सेल (Cell)** — पंक्ति व स्तंभ के प्रतिच्छेदन (intersection) का एकल बॉक्स; प्रत्येक सेल का एक अद्वितीय पता होता है, जैसे **A1, B2** (स्तंभ अक्षर + पंक्ति संख्या)।
- **सेल रेंज (Range)** — सेलों का समूह, जैसे A1:A10।
- **कॉलम (Column)** — अक्षरों (A, B, C...) से पहचाने जाते हैं (ऊर्ध्वाधर)।
- **रो (Row)** — संख्याओं (1, 2, 3...) से पहचानी जाती हैं (क्षैतिज)।

## मूल फंक्शन/फॉर्मूला (उच्च-यील्ड)

फॉर्मूला हमेशा **"="** चिह्न से शुरू होता है।

| फंक्शन | कार्य | उदाहरण |
|---|---|---|
| **SUM** | योग निकालना | `=SUM(A1:A10)` |
| **AVERAGE** | औसत निकालना | `=AVERAGE(A1:A10)` |
| **MAX** | अधिकतम मान | `=MAX(A1:A10)` |
| **MIN** | न्यूनतम मान | `=MIN(A1:A10)` |
| **COUNT** | संख्यात्मक मानों की गिनती | `=COUNT(A1:A10)` |
| **COUNTA** | खाली न होने वाले सेलों की गिनती | `=COUNTA(A1:A10)` |
| **COUNTIF** | शर्त के अनुसार गिनती | `=COUNTIF(A1:A10,">50")` |
| **IF** | सशर्त परिणाम | `=IF(A1>50,"Pass","Fail")` |
| **VLOOKUP** | ऊर्ध्वाधर खोज (किसी टेबल में मान खोजना) | `=VLOOKUP(A1,B1:D10,2,FALSE)` |
| **ROUND** | दशमलव तक गोल करना | `=ROUND(A1,2)` |

## सेल फॉर्मेटिंग

- संख्या प्रारूप — सामान्य (General), संख्या (Number), मुद्रा (Currency), प्रतिशत (Percentage), दिनांक (Date)।
- फॉन्ट, बॉर्डर, भरण रंग (Fill Color)।
- **सेल मर्ज (Merge Cells)** — कई सेलों को एक में मिलाना (जैसे शीर्षक हेतु)।
- **कंडीशनल फॉर्मेटिंग (Conditional Formatting)** — शर्त के आधार पर सेल का रंग/शैली स्वतः बदलना (जैसे 50 से कम मान लाल रंग में)।
- **फ्रीज़ पेन्स (Freeze Panes)** — स्क्रॉल करते समय हेडर पंक्ति/स्तंभ को स्थिर रखना।

## चार्ट (Chart)

Excel डेटा को दृश्य रूप में प्रस्तुत करने हेतु — **Insert टैब → Charts** से बनाया जाता है।

| चार्ट प्रकार | उपयोग |
|---|---|
| कॉलम/बार चार्ट | श्रेणियों की तुलना |
| लाइन चार्ट | समय के साथ रुझान (trend) दिखाना |
| पाई चार्ट | कुल का प्रतिशत विभाजन दिखाना |
| स्कैटर चार्ट | दो चरों के बीच संबंध |

## MS Excel शॉर्टकट कीज़ (उच्च-यील्ड)

| शॉर्टकट | कार्य |
|---|---|
| Ctrl+N | नई वर्कबुक |
| Ctrl+S | सेव करना |
| Ctrl+C / Ctrl+V | कॉपी / पेस्ट |
| Ctrl+Z | पूर्ववत् (Undo) |
| Ctrl+Arrow Key | डेटा क्षेत्र के अंत तक कूदना |
| Ctrl+Space | पूरा कॉलम चयन |
| Shift+Space | पूरी पंक्ति चयन |
| Ctrl+; | वर्तमान दिनांक डालना |
| Ctrl+Shift+; | वर्तमान समय डालना |
| F2 | सेल संपादित करना (Edit) |
| F4 | अंतिम क्रिया दोहराना / सेल संदर्भ (relative/absolute) बदलना |
| Ctrl+1 | Format Cells डायलॉग खोलना |
| Alt+= | स्वतः योग (AutoSum) |
| Ctrl+Page Down/Up | अगली/पिछली वर्कशीट पर जाना |

## महत्वपूर्ण अतिरिक्त तथ्य

- MS Excel की डिफ़ॉल्ट फाइल एक्सटेंशन **.xlsx** (पुराना संस्करण **.xls**) है।
- Excel में एक वर्कशीट में अधिकतम पंक्तियाँ = **10,48,576** व अधिकतम स्तंभ = **16,384 (XFD तक)** (Excel 2007 व बाद के संस्करणों में)।
- **AutoSum बटन (Σ)** — Home टैब में, चयनित सेलों का तुरंत योग करता है।
- **Absolute Reference** (जैसे `$A$1`) बनाम **Relative Reference** (जैसे `A1`) — फॉर्मूला कॉपी करते समय संदर्भ स्थिर रखने हेतु `$` चिह्न प्रयुक्त होता है।

## अभ्यास प्रश्न

1. A1 से A10 तक का योग निकालने का फॉर्मूला? — **=SUM(A1:A10)**
2. सेल संपादित करने की शॉर्टकट कुंजी? — **F2**
3. MS Excel की डिफ़ॉल्ट फाइल एक्सटेंशन? — **.xlsx**

## परीक्षा हेतु सबसे महत्वपूर्ण तथ्य

- SUM, AVERAGE, MAX, MIN, COUNT, IF — इन बुनियादी फंक्शनों का सिंटैक्स व उपयोग याद रखें।
- सेल पता प्रणाली (कॉलम अक्षर + पंक्ति संख्या, जैसे B5) व वर्कबुक-वर्कशीट-सेल का पदानुक्रम स्पष्ट रखें।
- .xlsx एक्सटेंशन व AutoSum (Alt+=) शॉर्टकट याद रखें।
