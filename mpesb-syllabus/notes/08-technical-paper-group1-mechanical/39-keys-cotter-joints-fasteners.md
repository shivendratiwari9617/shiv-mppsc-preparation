# Keys, Cotter Joints & Fasteners (चाबी, कील व फास्टनर)

## Key — Basic Function

A machine element inserted between a **shaft and a hub** (of a gear, pulley, coupling, etc.) to **prevent relative rotation** between them, ensuring torque is transmitted from the shaft to the mounted component (or vice versa) — fits into matching grooves (**keyways**) cut into both the shaft and the hub.

## Types of Keys

| Type | Description |
|---|---|
| **Sunk Key** | Half-embedded in the shaft's keyway, half in the hub's keyway — the most common type; sub-types: **Rectangular sunk key**, **Square sunk key**, **Parallel/Taper sunk key** (taper key has a slight taper on one face, driven in for a tight fit), **Gib-head key** (has a head for easy removal) |
| **Saddle Key** | Fits entirely within a keyway cut only in the **hub** (none in the shaft) — sits on a flat/curved seat on the shaft surface; relies mainly on **friction**, so has much lower torque capacity than a sunk key — used only for light duty |
| **Tangent Key** | Two keys installed at right angles (tangentially) to each other, both under compression — used for **heavy duty, reversible torque** applications |
| **Round Key (Pin Key)** | Circular cross-section, fits into a hole drilled partly in the shaft and partly in the hub |
| **Feather Key** | A sunk key that allows the hub to **slide axially** along the shaft while still transmitting torque (i.e., permits relative axial motion but prevents relative rotation) — used where a component (e.g., a gear on a gearbox shaft) needs to shift position along the shaft during operation |
| **Woodruff Key** | A semi-circular (half-moon shaped) key that fits into a curved seat in the shaft — self-aligning, commonly used on tapered shaft ends (automotive applications) |

### Key Failure Modes (design must check both, similar in spirit to riveted joint checks, point 35)
1. **Shear failure** — key shears along its length, at the shaft-hub interface plane.
2. **Crushing (Bearing/Compressive) failure** — key crushes due to compressive/bearing pressure against the sides of the keyway.

## Cotter Joint — Basic Function

A **temporary** (but rigid, non-rotating) fastening method used to connect two rods/members that are **subjected to axial tensile or compressive force** (not rotating torque, unlike a key) — e.g., joining piston rod to crosshead, or connecting two tie-rods.

### Cotter — Description
A flat wedge-shaped piece of metal, uniform thickness but tapered in width (typically tapered on one side only, at a small angle, e.g., 1:24 to 1:32), driven through matching **rectangular slots** in a **socket and spigot** (or sleeve/strap) arrangement to hold the two rod ends together, relying on the **wedge/taper action** for a tight, self-locking fit.

### Key Cotter Joint Types
| Type | Description |
|---|---|
| **Socket and Spigot Cotter Joint** | One rod end forms a socket (hollow), the other forms a spigot (solid, inserted into the socket) — cotter passes through slots in both, transversely |
| **Sleeve and Cotter Joint** | A separate hollow sleeve fits over the ends of both rods, with **two cotters** (one for each rod), passing through slots in the sleeve and each rod |

### Cotter vs Key — Key Distinction (frequently tested)
- **Key**: prevents **relative rotation** between a shaft and hub, transmits **torque**.
- **Cotter**: prevents **relative axial sliding** of two rod-like members, transmits **axial (tensile/compressive) force** — a fundamentally different load type and function, despite both being simple, wedge/friction-based, removable fasteners.

## Fasteners — Overview

### Temporary (Detachable) Fasteners

| Type | Description |
|---|---|
| **Bolt & Nut** | A threaded rod (bolt) passed through clearance holes in the parts to be joined, secured with a nut — most common detachable fastener; can be removed/reused |
| **Screw** | Similar to a bolt, but typically threads directly into one of the parts (no separate nut) |
| **Stud** | A rod threaded at **both** ends — one end screws permanently into one part, the other end takes a nut to secure the second part |
| **Pin** | Simple cylindrical fastener (e.g., cotter pin, split pin, dowel pin) — used for light-duty locating/locking, not primary load transmission in most cases |

### Permanent Fasteners
| Type | Description |
|---|---|
| **Rivet** | See point 35 — permanent, requires holes, cannot be reused |
| **Weld** | See point 35 — permanent, fuses material, cannot be disassembled |

## Screw Thread Basics (relevant to bolted fasteners)

| Term | Meaning |
|---|---|
| **Pitch** | Axial distance between two adjacent threads |
| **Lead** | Axial distance a nut advances in **one full rotation** — for a **single-start** thread, Lead = Pitch; for a **multi-start** thread (e.g., double-start), Lead = n × Pitch (n = number of starts) |
| **Major Diameter** | Largest diameter of the thread (outer diameter of an external/bolt thread) |
| **Minor (Core) Diameter** | Smallest diameter of the thread — the diameter used for **strength calculations** (a bolt's tensile strength is governed by its weaker core/root cross-section, not the major diameter) |

## Locking Devices for Bolted Joints
Used to prevent a nut from **loosening due to vibration** — e.g., **lock nut (jam nut)**, **split pin**, **spring washer**, **castellated nut with split pin** — an important practical/safety consideration wherever bolted joints are subject to vibration (very commonly tested as a general-knowledge/practical mechanical fact).

## Most Important Facts to Remember

- **Key**: prevents relative **rotation** between shaft and hub, transmits **torque**. **Cotter**: prevents relative **axial sliding** between two rod members, transmits **axial force** — the core distinguishing fact between these two similar-sounding elements.
- **Feather key** specifically allows **axial sliding of the hub** along the shaft while still preventing relative rotation (transmitting torque) — a distinctive, frequently tested key type.
- **Saddle key** relies mainly on friction (no shaft keyway) — much lower capacity than a sunk key, light duty only.
- Key must be checked against both **shear** and **crushing/bearing** failure — same dual-check logic pattern as riveted joints (point 35).
- Bolt strength calculations use the **minor (core) diameter**, not the major (outer) diameter — the weakest cross-section governs.
- **Lead = n × Pitch** (n = number of thread starts); for a single-start thread, **Lead = Pitch**.

## Practice Questions

1. What is the fundamental difference between a key and a cotter, in terms of the load/motion each is designed to prevent? → **A key prevents relative rotation between a shaft and hub (transmits torque); a cotter prevents relative axial sliding between two rod members (transmits axial force)**
2. Which type of key allows a hub to slide axially along a shaft while still transmitting torque? → **Feather key**
3. For bolt strength calculations, which diameter of the screw thread is used — major or minor? → **Minor (core) diameter**, since it represents the weakest cross-section
4. What relationship exists between lead and pitch for a double-start thread? → **Lead = 2 × Pitch**
