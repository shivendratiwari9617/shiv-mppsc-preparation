# सादृश्यता (Analogy) — शब्द, अक्षर, संख्या

**विषय:** तर्कशक्ति एवं विश्लेषणात्मक क्षमता | **परीक्षा-प्रासंगिकता:** MPESB सहित MPPSC, Vyapam/ESB, Patwari, MP Police — सादृश्यता प्रश्न हर रीजनिंग पेपर में आते हैं; यह बिंदु 34 (आकृति सादृश्यता) की भी वैचारिक नींव है।

---

## 1. सादृश्यता क्या है?

दो वस्तुओं/शब्दों/संख्याओं (A:B) के बीच एक **निश्चित संबंध** दिया जाता है; उसी संबंध के आधार पर दूसरी जोड़ी (C:D) को पूरा करना होता है। प्रारूप: **A : B :: C : ?**

---

## 2. शब्द सादृश्यता (Word Analogy) — संबंध के प्रकार

| संबंध-प्रकार | उदाहरण |
|---|---|
| पर्यायवाची | Big : Large :: Small : **Little** |
| विलोम | Hot : Cold :: Day : **Night** |
| कार्यकर्ता-स्थान | Teacher : School :: Doctor : **Hospital** |
| वस्तु-समूह | Tree : Forest :: Sheep : **Flock** |
| कारण-प्रभाव | Fire : Smoke :: Sun : **Heat/Light** |
| भाग-संपूर्ण | Wheel : Car :: Page : **Book** |
| उपकरण-प्रयोजन | Knife : Cut :: Pen : **Write** |
| जाति-उपजाति | Rose : Flower :: Mango : **Fruit** |

---

## 3. अक्षर सादृश्यता (Letter Analogy)

अक्षरों के बीच **स्थिति-आधारित** संबंध (बिंदु 1/6 की स्थिति-तालिका सीधे लागू होती है)।

**उदाहरण:** ACE : BDF :: GIK : **?**
पैटर्न: हर अक्षर +1 स्थान शिफ्ट (A→B, C→D, E→F)
GIK पर लागू करें: G→H, I→J, K→L → **उत्तर: HJL**

---

## 4. संख्या सादृश्यता (Number Analogy)

संख्याओं के बीच **गणितीय संबंध** (जोड़, गुणा, वर्ग, घन आदि)।

**उदाहरण:** 4 : 16 :: 5 : **?**
पैटर्न: n : n² (4²=16 है) → 5² = **25**

---

## 5. समाधान की रणनीति

1. पहली जोड़ी (A:B) के बीच **सटीक संबंध** पहचानें — क्या है A से B कैसे बना (अर्थ-आधारित, गणितीय, या स्थिति-आधारित)।
2. वही संबंध **तीसरे पद (C) पर लागू करके** चौथा पद (D) ज्ञात करें।
3. दिए गए **विकल्पों में जाँचें** कि कौन-सा विकल्प वही संबंध बनाए रखता है — कई बार एक ही जोड़ी में एक से अधिक संभावित संबंध दिख सकते हैं, सही उत्तर वही है जो विकल्पों में उपलब्ध व तर्कसंगत हो।

---

## 6. हल किया गया उदाहरण

**प्रश्न:** "Pen : Write :: Knife : ?"

**हल:**
- संबंध पहचानें: Pen का प्रयोजन "Write" करना है (उपकरण : कार्य संबंध)।
- वही संबंध Knife पर लागू करें: Knife का प्रयोजन क्या है? → **Cut**

**उत्तर: Cut**

## 7. अभ्यास हेतु उच्च-संभावना सूची (self-test)

| प्रश्न | उत्तर |

| Doctor : Patient :: Teacher : ? | Student |

## 8. याद रखने योग्य सबसे महत्वपूर्ण बिंदु (परीक्षा-केंद्रित)

1. **संबंध की श्रेणी पहचानना ही पहला व सबसे महत्वपूर्ण कदम है** — शब्द-सादृश्यता में यह अर्थ-आधारित (पर्याय, विलोम, कार्य आदि) होता है; संख्या/अक्षर में गणितीय/स्थिति-आधारित।
2. जल्दबाज़ी में पहला "दिखने वाला" संबंध न पकड़ें — विकल्पों के साथ मिलाकर देखें कि कौन-सा संबंध सभी विकल्पों में सबसे सुसंगत रूप से फिट बैठता है।
3. अक्षर सादृश्यता को हमेशा **स्थिति-संख्या** में बदलकर हल करें (बिंदु 6 से जुड़ाव)।
4. यह बिंदु शब्दावली (Hindi/English दोनों नोट-सेट के पर्यायवाची/विलोम बिंदु) के साथ सीधे जुड़ता है — मजबूत शब्दावली सादृश्यता प्रश्नों को तेज़ करती है।
