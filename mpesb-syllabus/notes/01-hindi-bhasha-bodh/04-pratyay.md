# प्रत्यय — कृत् प्रत्यय व तद्धित प्रत्यय

**विषय:** हिंदी भाषायी बोध (MPESB Prelims Subject-1) | **खंड:** शब्द-रचना / व्याकरण | **MPESB ट्रेंड:** अत्यंत उच्च — किसी शब्द में जुड़े प्रत्यय व मूल शब्द को पहचानना, तथा कृत्/तद्धित में भेद करना नियमित रूप से पूछा जाता है।

---

## 1. प्रत्यय क्या है?

**प्रत्यय** वे शब्दांश हैं जो किसी मूल शब्द या धातु (क्रिया) के **अंत/बाद** में जुड़कर नया शब्द बनाते हैं या उसके अर्थ में विशेषता जोड़ते हैं। उपसर्ग की तरह प्रत्यय का भी स्वतंत्र प्रयोग नहीं होता।

**उदाहरण:** सुंदर + ता = सुंदरता — यहाँ "ता" प्रत्यय जुड़कर विशेषण "सुंदर" को भाववाचक संज्ञा "सुंदरता" में बदल देता है।

### प्रत्यय के दो प्रमुख भेद
| भेद | जुड़ता है | बनने वाला शब्द कहलाता है |
|---|---|---|
| **कृत् प्रत्यय** | धातु/क्रिया के साथ | कृदंत |
| **तद्धित प्रत्यय** | संज्ञा, सर्वनाम, विशेषण (धातु को छोड़कर) के साथ | तद्धितांत |

**पहचानने की कुंजी:** प्रत्यय जिस मूल शब्द से जुड़ा है, यदि वह **धातु/क्रिया** है (जैसे पढ़ना, लिखना, गाना) तो **कृत् प्रत्यय**; यदि वह **संज्ञा/सर्वनाम/विशेषण** है (जैसे सुंदर, धन, भारत) तो **तद्धित प्रत्यय**।

## 2. कृत् प्रत्यय (धातु/क्रिया से जुड़ने वाले)

### (क) कर्तृवाचक कृत् प्रत्यय — "करने वाला" भाव
| प्रत्यय | उदाहरण |
|---|---|
| अक | गायक (गा+अक), लेखक (लिख्+अक), पाठक (पठ्+अक) |
| आक | तैराक (तैर+आक) |
| आड़ी | खिलाड़ी (खेल+आड़ी) |
| हार | होनहार (होना+हार) |
| वाला | पढ़नेवाला, लिखनेवाला |

### (ख) भाववाचक कृत् प्रत्यय — क्रिया के भाव/अवस्था का बोध
| प्रत्यय | उदाहरण |
|---|---|
| आई | लड़ाई (लड़+आई), पढ़ाई (पढ़+आई) |
| आवट | सजावट (सज+आवट), मिलावट (मिल+आवट), रुकावट (रुक+आवट) |
| आहट | घबराहट (घबरा+आहट), चिल्लाहट (चिल्ला+आहट) |
| आन | उड़ान (उड़+आन), मुस्कान (मुस्क+आन) |
| त | चाहत (चाह+त) |

### (ग) करणवाचक कृत् प्रत्यय — साधन/उपकरण का बोध
| प्रत्यय | उदाहरण |
|---|---|
| औना | खिलौना (खेल+औना), बिछौना (बिछ+औना) |
| नी | झाड़नी (झाड़+नी) |
| आ | झूला (झूल+आ) |

### (घ) कृदंत विशेषण (भूत/वर्तमान कालिक)
| प्रत्यय | उदाहरण |
|---|---|
| आ/या | पढ़ा (पढ़+आ), गया, खाया — भूतकालिक कृदंत |
| ता | करता, जाता, गाता — वर्तमानकालिक कृदंत |
| ता हुआ | जाता हुआ, खेलता हुआ |

## 3. तद्धित प्रत्यय (संज्ञा/सर्वनाम/विशेषण से जुड़ने वाले)

### (क) भाववाचक तद्धित — गुण/भाव का बोध (विशेषण → भाववाचक संज्ञा)
| प्रत्यय | उदाहरण |
|---|---|
| ता | सुंदरता (सुंदर+ता), गुरुता (गुरु+ता) |
| त्व | मनुष्यत्व (मनुष्य+त्व), अपनत्व (अपना+त्व) |
| पन | बचपन (बच्चा+पन) |
| आई | चतुराई (चतुर+आई), अच्छाई (अच्छा+आई) |
| आस | मिठास (मीठा+आस) |
| इमा | लालिमा (लाल+इमा) |
| पा | बुढ़ापा (बूढ़ा+पा) |

### (ख) संबंधवाचक/गुणवाचक तद्धित — किसी स्थान/वर्ग/गुण से संबंध
| प्रत्यय | उदाहरण |
|---|---|
| इक | सामाजिक (समाज+इक), आर्थिक (अर्थ+इक), धार्मिक (धर्म+इक), ऐतिहासिक (इतिहास+इक), वैज्ञानिक (विज्ञान+इक) |
| ईय | भारतीय (भारत+ईय) |
| ईण | ग्रामीण (ग्राम+ईण) |
| ईला | रंगीला (रंग+ईला) |
| वान | धनवान (धन+वान), गुणवान (गुण+वान) |
| मान | बुद्धिमान (बुद्धि+मान) |
| शाली | भाग्यशाली (भाग्य+शाली), शक्तिशाली (शक्ति+शाली) |
| इत | पीड़ित (पीड़ा+इत) |
| लु | दयालु (दया+लु), कृपालु (कृपा+लु) |

### (ग) ऊनतावाचक तद्धित — लघुता/छोटेपन का बोध
| प्रत्यय | उदाहरण |
|---|---|
| इया | लुटिया (लोटा+इया), बुढ़िया (बूढ़ा+इया), डिबिया (डिब्बा+इया) |
| ई | टोकरी (टोकरा+ई) |
| की | ढोलकी (ढोल+की) |

### (घ) व्यवसायवाचक/कर्तृवाचक तद्धित — पेशा/काम करने वाला
| प्रत्यय | उदाहरण |
|---|---|
| आर | सुनार (सोना+आर), लोहार (लोहा+आर), कुम्हार (कुम्भ+आर) |
| आरी | जुआरी (जुआ+आरी) |
| दार | दुकानदार (दुकान+दार), ईमानदार (ईमान+दार) |

## 4. कृत् बनाम तद्धित — भ्रम दूर करने की ट्रिक

- प्रश्न में दिया गया **मूल शब्द जाँचें**: क्या वह किसी क्रिया/धातु से बना है (पढ़ना→पाठक, लड़ना→लड़ाई) → **कृत् प्रत्यय**।
- क्या मूल शब्द पहले से ही संज्ञा/विशेषण है (सुंदर→सुंदरता, धन→धनवान, समाज→सामाजिक) → **तद्धित प्रत्यय**।
- कई प्रत्यय-रूप (जैसे "आई") दोनों श्रेणी में मिल सकते हैं — पढ़ाई (पढ़ना धातु से, कृत्) बनाम चतुराई (चतुर विशेषण से, तद्धित)। **हमेशा मूल शब्द की प्रकृति (धातु या नहीं) से तय करें, केवल प्रत्यय-रूप से नहीं।**

## 6. याद रखने योग्य सबसे महत्वपूर्ण बिंदु (MPESB Exam Points)

1. सबसे पहला व सबसे ज़्यादा पूछा जाने वाला प्रश्न-प्रकार: "किसी शब्द में मूल शब्द व प्रत्यय अलग कीजिए" — इसके लिए ऊपर की तालिकाएँ याद रखें।
2. **कृत् = धातु/क्रिया से; तद्धित = संज्ञा/सर्वनाम/विशेषण से** — यह एक-पंक्ति का नियम हर प्रश्न में सबसे पहले लगाएँ।
3. एक ही प्रत्यय-रूप (जैसे "आई", "ता") कृत् और तद्धित दोनों में आ सकता है — जाल में न फँसें, मूल शब्द जाँचें।
4. उपसर्ग (बिंदु 3) व प्रत्यय की सूचियाँ एक साथ भ्रमित न करें — उपसर्ग पहले जुड़ता है, प्रत्यय बाद में; दोनों की सूचियाँ अलग-अलग रटें।
