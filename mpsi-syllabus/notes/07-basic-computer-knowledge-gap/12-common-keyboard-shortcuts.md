# सामान्य कीबोर्ड शॉर्टकट (Ctrl+C/V/X/Z, Alt+Tab आदि)

यह वे shortcut keys हैं जो लगभग **हर Windows application** (Word, Excel, Browser, File Explorer आदि) में एक समान (universal) रूप से काम करती हैं — इसलिए प्रारंभिक परीक्षाओं में सर्वाधिक बार पूछा जाने वाला computer-topic यही है।

## Universal Shortcuts (सभी application में समान रूप से काम करते हैं)

| Shortcut | कार्य |
|---|---|
| **Ctrl+C** | Copy (चयनित सामग्री की प्रतिलिपि Clipboard में लेना) |
| **Ctrl+V** | Paste (Clipboard से सामग्री चिपकाना) |
| **Ctrl+X** | Cut (चयनित सामग्री हटाकर Clipboard में लेना) |
| **Ctrl+Z** | Undo (अंतिम क्रिया वापस लेना) |
| **Ctrl+Y** | Redo (Undo की गई क्रिया दोबारा करना) |
| **Ctrl+A** | Select All (सब कुछ चयनित करना) |
| **Ctrl+S** | Save (सहेजना) |
| **Ctrl+P** | Print |
| **Ctrl+N** | New (नई file/window) |
| **Ctrl+O** | Open (file खोलना) |
| **Ctrl+F** | Find (खोजना) |
| **Ctrl+W** | वर्तमान window/tab बंद करना |
| **Alt+F4** | सक्रिय (active) programme/window पूर्णतः बंद करना |
| **Alt+Tab** | खुले programmes के बीच स्विच करना |
| **Ctrl+Alt+Delete** | Task Manager/Lock/Sign-out विकल्प खोलना (Security screen) |
| **Ctrl+Shift+Esc** | सीधे Task Manager खोलना |
| **F1** | Help खोलना |
| **F2** | चयनित file/folder का नाम बदलना (Rename) |
| **F5** | Refresh (पृष्ठ/folder पुनः लोड करना) |
| **Windows Key** | Start Menu खोलना |
| **Windows Key + D** | सभी windows minimize कर Desktop दिखाना |
| **Windows Key + E** | File Explorer खोलना |
| **Windows Key + L** | Computer तुरंत Lock करना |
| **Esc** | वर्तमान क्रिया/menu रद्द करना |

## Clipboard की अवधारणा (क्यों Copy-Paste काम करता है)

**Clipboard** एक अस्थायी (temporary) storage क्षेत्र है जो operating system की memory में रहता है। जब Ctrl+C या Ctrl+X दबाते हैं, तो चयनित सामग्री Clipboard में चली जाती है; Ctrl+V दबाने पर वह Clipboard से खींचकर नए स्थान पर चिपक जाती है। Clipboard में एक समय में सामान्यतः केवल एक ही "item" रहता है — नई चीज़ copy करते ही पुरानी replace हो जाती है (आधुनिक Windows में Clipboard History — `Windows+V` — कई items रख सकती है)।

## Text Navigation Shortcuts

| Shortcut | कार्य |
|---|---|
| Home | पंक्ति के प्रारंभ में जाना |
| End | पंक्ति के अंत में जाना |
| Ctrl+Home | दस्तावेज़ के प्रारंभ में जाना |
| Ctrl+End | दस्तावेज़ के अंत में जाना |
| Ctrl+Right/Left Arrow | एक शब्द आगे/पीछे कर्सर ले जाना |
| Shift+Arrow Keys | चयन (selection) करना |
| Ctrl+Shift+Arrow | एक शब्द चयन करना |

|---|---|
| Ctrl+T | नया Tab खोलना |
| Ctrl+Shift+T | बंद किया गया Tab दोबारा खोलना |

## महत्वपूर्ण अतिरिक्त तथ्य

- Ctrl+C/Ctrl+V का आविष्कार Larry Tesler द्वारा माना जाता है — यह "Cut, Copy, and Paste" की अवधारणा को computer इतिहास की सबसे प्रभावशाली user-interface सुविधाओं में गिना जाता है।
- Mac computer में Windows की Ctrl key के स्थान पर **Command (⌘) key** प्रयुक्त होती है — यह cross-platform अंतर परीक्षा में कभी-कभी पूछा जाता है।
- **Alt+Tab** व **Alt+F4** में अंतर — Alt+Tab programmes के बीच switch करता है (कुछ बंद नहीं होता), जबकि Alt+F4 सक्रिय programme को पूरी तरह बंद कर देता है।

## अभ्यास प्रश्न

1. चयनित सामग्री की प्रतिलिपि लेने की shortcut key? — **Ctrl+C**
2. खुले programmes के बीच स्विच करने की shortcut? — **Alt+Tab**
3. File/folder का नाम बदलने की shortcut key? — **F2**
4. Computer तुरंत lock करने की shortcut? — **Windows Key + L**

## परीक्षा हेतु सबसे महत्वपूर्ण तथ्य

- Ctrl+C/V/X/Z/Y (Copy/Paste/Cut/Undo/Redo) — ये पाँच सबसे बुनियादी व सर्वाधिक पूछी जाने वाली shortcuts हैं, बिल्कुल न भूलें।
- Alt+Tab (switch) बनाम Alt+F4 (close) का अंतर स्पष्ट रखें।
- F2 (rename), F5 (refresh), Ctrl+Shift+Esc (Task Manager) — ये तीनों functional key shortcuts अक्सर पूछी जाती हैं।
