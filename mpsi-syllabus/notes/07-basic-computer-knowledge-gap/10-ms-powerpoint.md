# MS PowerPoint — स्लाइड निर्माण, ट्रांज़िशन, बेसिक फीचर्स

MS PowerPoint एक **Presentation Software** है — विचारों/data को क्रमबद्ध slides के माध्यम से दृश्य रूप में प्रस्तुत (present) करने हेतु प्रयुक्त होता है। सरकारी विभागों में training, review meetings व reports प्रस्तुत करने हेतु यह मानक tool है।

## मूल संरचना

- **Presentation** — पूरी PowerPoint file (.pptx), जिसमें कई slides होती हैं।
- **Slide** — एक individual "पृष्ठ", जिस पर text, चित्र, chart, video आदि रखे जाते हैं।
- **Slide Layout** — किसी slide पर content कैसे व्यवस्थित (arrange) होगा, उसका पूर्व-निर्धारित ढाँचा (जैसे Title Slide, Title and Content, Two Content, Blank)।
- **Slide Master** — एक "master template" जो पूरी presentation की सभी slides के लिए एक समान (consistent) डिज़ाइन, फॉन्ट व logo तय करता है — इसमें एक बार बदलाव करने से सभी slides स्वतः बदल जाती हैं।

## Slide निर्माण की प्रक्रिया

1. **New Slide** जोड़ना (Home टैब → New Slide, या Ctrl+M)।
2. Slide पर **Text Box, Picture, Table, Chart, SmartArt** आदि insert करना (Insert टैब से)।
3. **Design** टैब से theme/रंग-योजना (color scheme) चुनना।
4. **Slide Sorter View** में slides का क्रम बदलना (drag-and-drop से पुनर्व्यवस्थित करना)।

## Transitions व Animations — अंतर स्पष्ट रखें (Common Confusion)

| शब्द | अर्थ |
|---|---|
| **Transition** | एक slide से दूसरी slide में बदलते समय दिखने वाला प्रभाव (जैसे Fade, Wipe, Zoom) — **Transitions टैब** से लागू होता है, यह पूरी slide पर लागू होता है |
| **Animation** | किसी slide के अंदर एक individual element (text, image) के प्रकट/गायब होने या हिलने का प्रभाव — **Animations टैब** से लागू होता है, यह एक ही slide के भीतर के objects पर लागू होता है |

## Views (दृश्य प्रकार)

| View | उपयोग |
|---|---|
| **Normal View** | सामान्य editing हेतु डिफ़ॉल्ट view |
| **Slide Sorter View** | सभी slides को thumbnail के रूप में देखना व क्रम बदलना |
| **Slide Show View (F5)** | पूर्ण-screen पर live presentation चलाना |
| **Notes Page View** | Presenter के लिए लिखे गए speaker notes देखना/edit करना |
| **Reading View** | Window के अंदर ही presentation देखना (full-screen के बिना) |

## MS PowerPoint Shortcut Keys (उच्च-यील्ड)

| Shortcut | कार्य |
|---|---|
| F5 | प्रारंभ से Slide Show चलाना |
| Shift+F5 | वर्तमान slide से Slide Show चलाना |
| Ctrl+M | नई slide जोड़ना |
| Ctrl+D | चयनित object/slide की duplicate copy बनाना |
| Esc | Slide Show से बाहर निकलना |
| Ctrl+N | नई presentation |
| Ctrl+S | Save करना |
| Ctrl+P | Print करना |
| B (Slide Show के दौरान) | Screen काली (black) करना |
| W (Slide Show के दौरान) | Screen सफेद (white) करना |

## महत्वपूर्ण अतिरिक्त तथ्य

- MS PowerPoint की default file extension **.pptx** (पुराना संस्करण **.ppt**) है।
- **SmartArt** — जानकारी को visual diagram (जैसे flowchart, hierarchy chart) के रूप में तुरंत प्रस्तुत करने की सुविधा।
- **Speaker Notes** — presenter के अपने संदर्भ हेतु स्लाइड के नीचे लिखे नोट्स, जो audience को slide show के दौरान नहीं दिखते (जब तक presenter view प्रयुक्त न हो)।
- **Presenter View** — प्रस्तुतकर्ता की screen पर notes व अगली slide का preview दिखता है, जबकि audience की screen पर केवल वर्तमान slide दिखती है।

## अभ्यास प्रश्न

1. एक slide से दूसरी slide में बदलते समय का प्रभाव क्या कहलाता है? — **Transition**
2. Slide show प्रारंभ से चलाने की shortcut key? — **F5**
3. MS PowerPoint की default file extension? — **.pptx**

## परीक्षा हेतु सबसे महत्वपूर्ण तथ्य

- Transition (slide-to-slide प्रभाव) बनाम Animation (slide के अंदर object का प्रभाव) का अंतर स्पष्ट रखें — यह सबसे आम confusion-प्रश्न है।
- F5 (शुरू से) व Shift+F5 (वर्तमान slide से) slide show शुरू करने की shortcuts याद रखें।
- .pptx extension व मूल views (Normal, Slide Sorter, Slide Show) से परिचित रहें।
