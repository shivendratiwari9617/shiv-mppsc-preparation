# अनेक शब्दों के लिए एक शब्द (One-Word Substitution)

**विषय:** हिंदी भाषायी बोध | **खंड:** शब्दावली / व्याकरण | **परीक्षा-प्रासंगिकता:** MPSI सहित MPPSC, Vyapam/ESB, Patwari, MP Police — किसी वाक्यांश के लिए उपयुक्त एक शब्द चुनना एक स्थायी प्रश्न-प्रकार है।

---

## 1. परिभाषा

जब किसी **वाक्यांश (कई शब्दों के समूह)** के स्थान पर **एक ही शब्द** वही भाव पूर्ण रूप से व्यक्त कर दे, तो उसे **"अनेक शब्दों के लिए एक शब्द"** कहते हैं। यह भाषा को संक्षिप्त व प्रभावी बनाता है। जैसे: "जो कहा न जा सके" = **अकथनीय**।

---

## 2. व्यक्ति के गुण/स्वभाव आधारित

| वाक्यांश | एक शब्द |
|---|---|
| जो कहा न जा सके | अकथनीय/अकथ्य |
| जो देखा न जा सके | अदृश्य |
| जो जीता न जा सके | अजेय |
| जो पढ़ा-लिखा न हो | अनपढ़/निरक्षर |
| जो सब कुछ जानता हो | सर्वज्ञ |
| जो पहले कभी न हुआ हो | अभूतपूर्व |
| जिसकी कोई सीमा न हो | असीम/अनंत |
| जिसे बुलाया न गया हो | अनाहूत |
| जो उपकार मानने वाला हो | कृतज्ञ |
| जो उपकार न मानने वाला हो | कृतघ्न |
| जो कम बोलता हो | मितभाषी |
| जो बहुत बोलता हो | वाचाल |
| जो सब जगह व्याप्त हो | सर्वव्यापी |
| जिसे मृत्यु का भय न हो | निर्भय/अभय |
| जो आँखों से न देख सके | अंधा/नेत्रहीन |
| जो कानों से न सुन सके | बहरा |
| जो अपनी बात पर अड़ा रहे | हठी/जिद्दी |
| जो धर्म का आचरण करे | धर्मात्मा |
| जो शरण में आया हो | शरणागत |
| जिसका कोई शत्रु न हो | अजातशत्रु |
| जो दूसरों की भलाई चाहता हो | परोपकारी/हितैषी |
| जो अपने देश से प्रेम करता हो | देशभक्त |
| जिसका जन्म अच्छे कुल में हुआ हो | कुलीन |
| जो शीघ्र क्रोधित हो जाए | क्रोधी |

---

## 3. संबंध-वाचक

| वाक्यांश | एक शब्द |
|---|---|
| जो पहले जन्मा हो (बड़ा भाई) | अग्रज |
| जो बाद में जन्मा हो (छोटा भाई) | अनुज |
| जिस स्त्री का पति मर चुका हो | विधवा |
| जिसकी पत्नी मर चुकी हो (पुरुष) | विधुर |
| जिसका पति जीवित हो | सधवा |
| जो नारी संतान उत्पन्न न कर सके | बांझ |

---

## 4. समय-संबंधी

| वाक्यांश | एक शब्द |
|---|---|
| जो प्रतिदिन होता हो | दैनिक/नित्य |
| जो महीने में एक बार हो | मासिक |
| जो वर्ष में एक बार हो | वार्षिक |
| जो सप्ताह में एक बार हो | साप्ताहिक |
| जो हमेशा रहने वाला हो | शाश्वत/चिरस्थायी |
| जो थोड़ी देर के लिए हो | क्षणिक |

---

## 5. स्थान-संबंधी

| वाक्यांश | एक शब्द |
|---|---|
| रहने का स्थान | आवास/निवास |
| जहाँ पुस्तकें रखी जाती हैं | पुस्तकालय |
| जहाँ शव जलाए जाते हैं | श्मशान |
| जहाँ जल भरा रहता हो | जलाशय |
| जहाँ अनाथ बच्चे रखे जाते हैं | अनाथालय |
| जहाँ रोगियों का इलाज हो | चिकित्सालय/अस्पताल |
| स्त्रियों के लिए विशेष/वर्जित स्थान (राजमहल में) | अंतःपुर/रनिवास |

---

## 6. अन्य महत्वपूर्ण

| वाक्यांश | एक शब्द |
|---|---|
| जो कठिनाई से प्राप्त हो | दुर्लभ |
| जो सरलता से प्राप्त हो | सुलभ |
| जो कहा गया हो | कथित |
| जो पूछने योग्य हो | प्रष्टव्य |
| जो कानून के विरुद्ध हो | अवैध/गैरकानूनी |
| जो सबके साथ समान व्यवहार करे | निष्पक्ष |

---

## 7. सावधानी — भ्रामक/दोहरे-अर्थ वाले शब्द

**"अमूल्य"** पर विशेष ध्यान दें — इसका शाब्दिक अर्थ "जिसका मूल्य न हो" लगता है, पर वास्तविक प्रचलित अर्थ है **"जिसका मूल्य आँका न जा सके" यानी बहुमूल्य/अत्यंत कीमती** (मूल्यहीन नहीं!)। यह सबसे अधिक भ्रमित करने वाला शब्द है — परीक्षा में इसका सही (बहुमूल्य वाला) अर्थ ही सही माना जाता है।

---

## 8. अभ्यास हेतु उच्च-संभावना सूची (self-test)

| वाक्यांश | एक शब्द |
|---|---|
| जो सब कुछ जानता हो | सर्वज्ञ |
| जो उपकार न मानने वाला हो | कृतघ्न |
| जिसकी कोई सीमा न हो | असीम |
| जो पहले जन्मा हो | अग्रज |
| जो महीने में एक बार हो | मासिक |
| जहाँ शव जलाए जाते हैं | श्मशान |
| जो कठिनाई से प्राप्त हो | दुर्लभ |
| जिसका कोई शत्रु न हो | अजातशत्रु |

---

## 9. याद रखने योग्य सबसे महत्वपूर्ण बिंदु (परीक्षा-केंद्रित)

1. वाक्यांश को ध्यान से पढ़ें — "जो न हो" (निषेधात्मक) और "जो हो" (सकारात्मक) के बीच अंतर पकड़ें, अक्सर विकल्पों में उल्टे अर्थ वाला शब्द भी दिया जाता है (जैसे कृतज्ञ/कृतघ्न को उलझाना)।
2. **कृतज्ञ-कृतघ्न, विधवा-विधुर, अग्रज-अनुज, सधवा-बांझ** जैसे विपरीत-अर्थी जोड़े साथ-साथ याद रखें — ये अक्सर भ्रम पैदा करते हैं और साथ पूछे जाते हैं।
3. **"अमूल्य"** जैसे भ्रामक शब्दों (सेक्शन 7) को विशेष रूप से याद रखें — शाब्दिक अनुवाद से गलत उत्तर मिल सकता है।
4. यह विषय बिंदु 11 (पर्यायवाची) व बिंदु 12 (विलोम) से जुड़ा है — कई एक-शब्द उत्तर वहाँ की सूचियों में भी पर्याय के रूप में दिखेंगे, तीनों सूचियाँ एक साथ पढ़ने से समय बचता है।
