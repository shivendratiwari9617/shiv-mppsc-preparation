# समास — तत्पुरुष, द्वंद्व, बहुव्रीहि, अव्ययीभाव, द्विगु, कर्मधारय

**विषय:** हिंदी भाषायी बोध (MPSI Prelims Subject-1) | **खंड:** शब्द-रचना / व्याकरण | **MPSI ट्रेंड:** अत्यंत उच्च — समास-विग्रह और समास-भेद पहचानने के प्रश्न लगभग हर पेपर में आते हैं।

---

## 1. समास क्या है?

**समास** का अर्थ है "संक्षेप"। जब दो या दो से अधिक शब्द (पद) आपस में मिलकर एक नया, संक्षिप्त और सार्थक शब्द बनाते हैं, और इस मेल में बीच की विभक्तियों (परसर्गों — का, के, की, को, से, में, पर आदि) का लोप हो जाता है, तो उसे **समास** कहते हैं।

### समास के अंग
| पद | अर्थ |
|---|---|
| **पूर्वपद** | समस्त पद का पहला शब्द |
| **उत्तरपद** | समस्त पद का दूसरा (अंतिम) शब्द |
| **समस्त पद (सामासिक शब्द)** | समास से बना संक्षिप्त शब्द, जैसे "राजपुत्र" |
| **समास-विग्रह** | समस्त पद को वापस मूल रूप (विभक्ति सहित) में अलग करना, जैसे "राजा का पुत्र" |

**उदाहरण:** राजपुत्र (समस्त पद) → पूर्वपद: राजा, उत्तरपद: पुत्र → विग्रह: राजा का पुत्र

### समास और संधि में अंतर (संक्षिप्त पुनरावृत्ति)
संधि केवल **वर्णों** (ध्वनियों) का मेल है — जैसे विद्या+आलय=विद्यालय। समास **शब्दों (पदों)** का मेल है, जिसमें विभक्ति का लोप होता है — जैसे राजा+का+पुत्र=राजपुत्र। **विग्रह में यदि विभक्ति/परसर्ग जुड़े तो समास है; यदि केवल ध्वनि जुड़े तो संधि है।**

## 2. समास के भेद — त्वरित अवलोकन

MPSI पाठ्यक्रम में समास के **6 प्रमुख भेद** पढ़ने होते हैं:

| क्र. | भेद | प्रधान पद | मूल पहचान |
|---|---|---|---|
| 1 | अव्ययीभाव | पूर्वपद | पूरा पद अव्यय (क्रिया-विशेषण) जैसे काम करता है |
| 2 | तत्पुरुष | उत्तरपद | पदों के बीच कारक-विभक्ति (को, से, के लिए, का, में आदि) का लोप |
| 3 | कर्मधारय | दोनों पद समान कोटि | विशेषण-विशेष्य या उपमान-उपमेय संबंध |
| 4 | द्विगु | उत्तरपद | पूर्वपद संख्यावाचक, समूह/समाहार का बोध |
| 5 | द्वंद्व | दोनों पद प्रधान | 'और/या/अथवा' का लोप |
| 6 | बहुव्रीहि | कोई पद नहीं (अन्य/तीसरा अर्थ प्रधान) | समस्त पद किसी तीसरे व्यक्ति/वस्तु का बोध कराए |

## 3. अव्ययीभाव समास

**पहचान:** पूर्वपद अव्यय/उपसर्ग होता है (यथा, प्रति, आ, भर, यावत्, निः, बे आदि) और पूरा समस्त पद अव्यय (क्रिया-विशेषण) की तरह प्रयुक्त होता है — अर्थात उसका रूप लिंग/वचन/कारक से नहीं बदलता।

| समस्त पद | विग्रह |
|---|---|
| यथाशक्ति | शक्ति के अनुसार |
| यथासंभव | जैसा संभव हो |
| यथाक्रम | क्रम के अनुसार |
| यथाविधि | विधि के अनुसार |
| आजन्म | जन्म से लेकर (मृत्युपर्यंत) |
| आमरण | मृत्यु तक |
| प्रतिदिन | प्रत्येक दिन |
| प्रतिक्षण | हर क्षण |
| भरपेट | पेट भरकर |
| भरसक | सकभर (जितनी शक्ति हो उतना) |
| निडर | डर के बिना |
| निस्संदेह | संदेह के बिना |

## 4. तत्पुरुष समास

**पहचान:** उत्तरपद प्रधान होता है; पूर्वपद और उत्तरपद के बीच जो कारक-विभक्ति (कर्ता को छोड़कर शेष 6 कारकों में से कोई) लुप्त होती है, उसी के आधार पर इसके 6 उपभेद बनते हैं।

| उपभेद | कारक/विभक्ति | उदाहरण | विग्रह |
|---|---|---|---|
| कर्म तत्पुरुष | को | ग्रामगत | ग्राम को गत (गया हुआ) |
| | | स्वर्गप्राप्त | स्वर्ग को प्राप्त |
| करण तत्पुरुष | से/द्वारा | मनचाहा | मन से चाहा |
| | | तुलसीकृत | तुलसी द्वारा कृत (रचित) |
| | | शराहत | शर (बाण) से आहत |
| सम्प्रदान तत्पुरुष | के लिए | रसोईघर | रसोई के लिए घर |
| | | विद्यालय | विद्या के लिए आलय |
| | | गौशाला | गौ के लिए शाला |
| अपादान तत्पुरुष | से (अलग होने का भाव) | देशनिकाला | देश से निकाला |
| | | ऋणमुक्त | ऋण से मुक्त |
| | | पदच्युत | पद से च्युत |
| संबंध तत्पुरुष | का/के/की | राजपुत्र | राजा का पुत्र |
| | | गंगाजल | गंगा का जल |
| | | सेनापति | सेना का पति (स्वामी) |
| अधिकरण तत्पुरुष | में/पर | नगरवास | नगर में वास |
| | | आपबीती | आप पर बीती |
| | | दानवीर | दान में वीर |

### नञ् तत्पुरुष (निषेधात्मक तत्पुरुष) — MPSI में अक्सर पूछा जाता है
जहाँ पूर्वपद "न" (निषेध) का बोध कराए: अनपढ़ = न पढ़ा हुआ; अनदेखा = न देखा हुआ; नास्तिक = न आस्तिक; असत्य = न सत्य

## 5. कर्मधारय समास

**पहचान:** पूर्वपद और उत्तरपद में **विशेषण-विशेष्य** या **उपमान-उपमेय** का संबंध होता है, और दोनों पद एक ही विभक्ति (कारक) में होते हैं — यहाँ तत्पुरुष जैसा कोई कारक-चिह्न लुप्त नहीं होता, बल्कि एक पद दूसरे की विशेषता बताता है।

### (क) विशेषण-पूर्वपद कर्मधारय
| समस्त पद | विग्रह |
|---|---|
| नीलकमल | नीला कमल |
| महादेव | महान देव |
| पीतांबर | पीला अंबर (वस्त्र) |
| महात्मा | महान आत्मा |
| श्वेतांबर | श्वेत अंबर |

### (ख) उपमान कर्मधारय (उपमान — जिससे तुलना हो — पूर्वपद में)
| समस्त पद | विग्रह |
|---|---|
| घनश्याम | घन (बादल) के समान श्याम |
| कमलनयन | कमल के समान नयन |
| चंद्रमुख | चंद्र के समान मुख |

### (ग) उपमेय कर्मधारय (उपमेय — जिसकी तुलना हो — पूर्वपद में)
| समस्त पद | विग्रह |
|---|---|
| चरणकमल | चरण रूपी कमल |
| मुखचंद्र | मुख रूपी चंद्र |
| विद्याधन | विद्या रूपी धन |

**MPSI ट्रिक — पीतांबर/चतुर्भुज जैसे शब्द दोहरी पहचान वाले होते हैं:** "पीतांबर" जब सामान्य अर्थ (पीले रंग का वस्त्र) में हो तो **कर्मधारय** है; जब विशेष नाम (विष्णु — पीला वस्त्र धारण करने वाला) के अर्थ में प्रयुक्त हो तो **बहुव्रीहि** है। प्रश्न में दिए गए विग्रह/अर्थ के अनुसार ही भेद तय करें।

## 6. द्विगु समास

**पहचान:** पूर्वपद **संख्यावाचक** होता है और समस्त पद किसी **समूह या समाहार** का बोध कराता है।

| समस्त पद | विग्रह |
|---|---|
| नवरात्र | नौ रात्रियों का समूह |
| सप्ताह | सात दिनों का समूह |
| त्रिलोक | तीन लोकों का समूह |
| चौराहा | चार राहों का समूह |
| पंसेरी | पाँच सेर का समूह |
| त्रिवेणी | तीन वेणियों (नदियों) का समूह |
| दोपहर | दो पहरों का समूह |
| नवग्रह | नौ ग्रहों का समूह |
| पंचवटी | पाँच वटवृक्षों का समूह/स्थान |

## 7. द्वंद्व समास

**पहचान:** दोनों पद **समान रूप से प्रधान** होते हैं; विग्रह में सामान्यतः **'और', 'या', 'अथवा'** का प्रयोग होता है।

| समस्त पद | विग्रह |
|---|---|
| माता-पिता | माता और पिता |
| राम-लक्ष्मण | राम और लक्ष्मण |
| दाल-रोटी | दाल और रोटी |
| नर-नारी | नर और नारी |
| सुख-दुख | सुख और दुख |
| रात-दिन | रात और दिन |
| भला-बुरा | भला या बुरा |

### द्वंद्व के 3 उपभेद
1. **इतरेतर द्वंद्व** — दोनों पद अपना स्वतंत्र अर्थ बनाए रखते हैं: राम-लक्ष्मण, माता-पिता
2. **समाहार द्वंद्व** — दोनों पद मिलकर एक सामान्य/सामूहिक अर्थ देते हैं: दाल-रोटी (= भोजन मात्र), हाथ-पैर (= शरीर/मेहनत)
3. **वैकल्पिक द्वंद्व** — 'या/अथवा' का भाव, प्रायः विपरीतार्थी शब्दों में: भला-बुरा, पाप-पुण्य, जीवन-मरण

---

## 8. बहुव्रीहि समास

**पहचान:** समस्त पद में **कोई भी पद प्रधान नहीं** होता — दोनों पद मिलकर किसी **तीसरे (अन्य) व्यक्ति/वस्तु** की विशेषता बताते हैं। विग्रह वाक्य में सामान्यतः **"जिसका", "जिसके", "जिसकी"** जैसे शब्द आते हैं।

| समस्त पद | विग्रह | अर्थ (तीसरा पद) |
|---|---|---|
| दशानन | दस हैं आनन (मुख) जिसके | रावण |
| चक्रपाणि | चक्र है पाणि (हाथ) में जिसके | विष्णु |
| नीलकंठ | नीला है कंठ जिसका | शिव |
| लंबोदर | लंबा है उदर जिसका | गणेश |
| त्रिनेत्र | तीन नेत्र हैं जिसके | शिव |
| गजानन | गज जैसा आनन है जिसका | गणेश |
| चतुर्भुज | चार भुजाएँ हैं जिसकी | विष्णु |
| वीणापाणि | वीणा है पाणि में जिसके | सरस्वती |
| पीतांबर | पीला है अंबर (वस्त्र) जिसका | विष्णु |

### बहुव्रीहि बनाम कर्मधारय/द्विगु — यह अंतर सबसे ज़्यादा पूछा जाता है
- **कर्मधारय/द्विगु** में समस्त पद अपने ही अवयवों में से अर्थ लेता है — नीलकमल = कमल की एक जाति (कमल ही प्रधान रहता है); त्रिलोक = तीनों लोकों का समूह (लोक ही प्रधान अर्थ है)।
- **बहुव्रीहि** में समस्त पद अपने अवयवों से हटकर किसी और (तीसरे) की विशेषता बन जाता है — नीलकंठ का अर्थ 'कंठ' नहीं बल्कि 'शिव' है।
- **ट्रिक:** विग्रह वाक्य में "जिसका/जिसके/जिसकी" आए और वह समस्त पद किसी व्यक्ति-विशेष/देवता का बोध कराए → **बहुव्रीहि** समझें।

---

## 9. समास पहचानने की त्वरित ट्रिक (Quick Identification)

1. विग्रह में **"और/या/अथवा"** आए → **द्वंद्व**
2. विग्रह **"जिसका/जिसकी/जिसके"** रूप में हो और तीसरे अर्थ की ओर संकेत करे → **बहुव्रीहि**
3. पहला पद **संख्यावाचक** हो और समूह/समाहार का बोध हो → **द्विगु**
4. पहला पद **विशेषण** हो (या उपमा का भाव हो) और दोनों पद मिलकर तीसरी वस्तु का बोध न कराएँ → **कर्मधारय**
5. पहला पद **अव्यय/उपसर्ग** (यथा, प्रति, आ, भर, निः आदि) हो और पूरा पद क्रिया-विशेषण जैसे काम करे → **अव्ययीभाव**
6. शेष सभी — जहाँ दोनों पदों के बीच कारक-चिह्न (को, से, के लिए, का, में/पर) लुप्त हो और उत्तरपद प्रधान हो → **तत्पुरुष**

## 11. याद रखने योग्य सबसे महत्वपूर्ण बिंदु (MPSI Exam Points)

1. समास के **6 भेद** और उनके नाम क्रम से याद रखें — अव्ययीभाव, तत्पुरुष, कर्मधारय, द्विगु, द्वंद्व, बहुव्रीहि।
2. **तत्पुरुष के 6 उपभेद** कारक-आधारित हैं (कर्म, करण, सम्प्रदान, अपादान, संबंध, अधिकरण) — कौन-सी विभक्ति किस उपभेद में लुप्त होती है, यह तालिका (सेक्शन 4) कंठस्थ करें।
3. **कर्मधारय vs बहुव्रीहि** का अंतर सबसे ज़्यादा भ्रम पैदा करता है — पीतांबर, चतुर्भुज जैसे दोहरी-पहचान वाले शब्द ध्यान से पढ़ें (सेक्शन 5 व 8 की ट्रिक याद रखें)।
4. **द्वंद्व और द्विगु** को न उलझाएँ — द्वंद्व में दोनों पद बराबर व स्वतंत्र प्रधान होते हैं ('और' का भाव); द्विगु में पहला पद संख्या होकर समूह बताता है।
5. समास-विग्रह प्रश्नों में सबसे पहले यह देखें कि विग्रह वाक्य में कौन-सा शब्द ("और", "जिसका", संख्या, "के लिए/से/का/में") आ रहा है — वही भेद तय करने की कुंजी है (सेक्शन 9 की ट्रिक लिस्ट)।
