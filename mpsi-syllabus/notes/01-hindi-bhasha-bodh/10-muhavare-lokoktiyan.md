# मुहावरे व लोकोक्तियाँ — सामान्य प्रयोग व अर्थ

**विषय:** हिंदी भाषायी बोध | **खंड:** शब्दावली / व्याकरण | **परीक्षा-प्रासंगिकता:** MPSI सहित MPPSC, Vyapam/ESB, Patwari, MP Police — लगभग हर MP राज्य परीक्षा में मुहावरे व लोकोक्तियों का अर्थ पूछना एक स्थायी खंड होता है। यह विशुद्ध रूप से शब्दावली-स्मरण आधारित विषय है, इसलिए सूची जितनी व्यापक याद हो उतना लाभ मिलता है।

---

## 1. मुहावरा और लोकोक्ति में अंतर

| बिंदु | मुहावरा (Idiom) | लोकोक्ति/कहावत (Proverb) |
|---|---|---|
| रूप | **अपूर्ण** वाक्यांश — वाक्य में ढालकर प्रयोग होता है | **पूर्ण** वाक्य — ज्यों का त्यों प्रयुक्त होता है |
| परिवर्तन | काल, पुरुष, वचन के अनुसार क्रिया-रूप बदलता है | कोई परिवर्तन नहीं, स्थिर रूप में प्रयुक्त |
| उद्देश्य | किसी भाव/क्रिया की विशेष (लाक्षणिक) अभिव्यक्ति | अनुभव-सिद्ध उपदेश/शिक्षा/नैतिक संदेश |
| उदाहरण | नाकों चने चबाना (नाकों चने चबवा दिए, चबा रहा है आदि रूप बदलते हैं) | अब पछताए होत क्या जब चिड़िया चुग गई खेत (सदैव यही रूप) |

**पहचानने की ट्रिक:** यदि वाक्यांश अपने-आप में **पूर्ण वाक्य** है और बिना बदले सीधे उद्धृत किया जा सकता है → **लोकोक्ति**। यदि उसे वाक्य में ढालने के लिए क्रिया-रूप बदलना पड़े (चबाना→चबाता है→चबा रहा था) → **मुहावरा**।

| दाँतों तले उंगली दबाना | आश्चर्यचकित होना |

| जबान पर ताला लगाना | चुप हो जाना |

## 3. उच्च-संभावना मुहावरे — अन्य सामान्य

| मुहावरा | अर्थ |
|---|---|
| नौ दो ग्यारह होना | भाग जाना |
| नाकों चने चबाना | बहुत परेशान करना/होना |
| टका सा जवाब देना | साफ इनकार करना |
| कमर कसना | तैयार होना |
| खून का घूँट पीना | अपमान सहकर चुप रह जाना |
| गागर में सागर भरना | थोड़े शब्दों में बड़ी बात कहना |
| चादर से बाहर पैर फैलाना | सामर्थ्य से अधिक खर्च करना |
| चिकना घड़ा होना | निर्लज्ज होना |
| छक्के छुड़ाना | बुरी तरह पराजित करना |
| टस से मस न होना | बिल्कुल न हिलना/अडिग रहना |
| ठिकाने लगाना | खत्म कर देना/निपटाना |
| दाल न गलना | सफल न होना |
| दूध का दूध पानी का पानी करना | उचित न्याय करना |
| नमक-मिर्च लगाना | बात बढ़ा-चढ़ाकर कहना |
| पापड़ बेलना | कठिन परिश्रम करना |
| बाल-बाल बचना | मुश्किल से बचना |
| लोहा लेना | मुकाबला करना |

| ईंट से ईंट बजाना | पूरी तरह नष्ट कर देना |
| आसमान से बातें करना | बहुत ऊँचा/बुलंद होना |
| आग में घी डालना | क्रोध या समस्या को और बढ़ाना |

| खरी-खोटी सुनाना | डाँटना/भला-बुरा कहना |
| गड़े मुर्दे उखाड़ना | पुरानी बातें फिर से याद दिलाना |

## 4. उच्च-संभावना लोकोक्तियाँ (कहावतें)

| लोकोक्ति | अर्थ |
|---|---|
| अंधों में काना राजा | मूर्खों के बीच थोड़ा योग्य व्यक्ति भी श्रेष्ठ माना जाता है |
| अब पछताए होत क्या जब चिड़िया चुग गई खेत | अवसर बीत जाने पर पछताना व्यर्थ है |
| आम के आम गुठलियों के दाम | एक साथ दोहरा लाभ |
| ऊँट के मुँह में जीरा | आवश्यकता से बहुत कम मिलना |
| एक पंथ दो काज | एक कार्य से दो लाभ |
| काठ की हांडी बार-बार नहीं चढ़ती | छल-कपट बार-बार नहीं चलता |
| घर का जोगी जोगड़ा, आन गाँव का सिद्ध | अपने व्यक्ति की योग्यता पहचानी नहीं जाती, बाहर वाले को अधिक सम्मान मिलता है |
| घर की मुर्गी दाल बराबर | अपनी चीज़ की कद्र नहीं होती |
| घर का भेदी लंका ढाए | आंतरिक व्यक्ति द्वारा भेद खोलने से बड़ा नुकसान होता है |
| चोर की दाढ़ी में तिनका | अपराधी स्वयं ही अपनी गलती से शंकित रहता है |
| जिसकी लाठी उसकी भैंस | शक्तिशाली की ही चलती है |
| नाच न जाने आँगन टेढ़ा | अपनी अयोग्यता छिपाकर परिस्थिति को दोष देना |
| नौ नकद न तेरह उधार | उधार से नकद अच्छा |
| बंदर क्या जाने अदरक का स्वाद | मूर्ख व्यक्ति गुणी वस्तु का महत्व नहीं समझ सकता |
| बिल्ली के भाग्य से छींका टूटा | बिना प्रयास लाभ मिल जाना |
| मुँह में राम बगल में छुरी | ऊपर से मीठा बोलना पर भीतर बुरा इरादा रखना |
| अधजल गगरी छलकत जाए | कम ज्ञानी व्यक्ति अधिक दिखावा करता है |
| आगे कुआं पीछे खाई | दोनों ओर से मुसीबत |
| ऊँची दुकान फीका पकवान | दिखावा अधिक, गुणवत्ता कम |
| एक अनार सौ बीमार | वस्तु सीमित, चाहने वाले अनेक |
| खोदा पहाड़ निकली चुहिया | बड़ी मेहनत का बहुत छोटा परिणाम |
| जैसी करनी वैसी भरनी | जैसा कर्म वैसा फल |
| दूध का जला छाछ भी फूंक-फूंक कर पीता है | एक बार धोखा खाने पर हर बात में सावधान रहना |
| सूप बोले तो बोले, छलनी क्यों बोले जिसमें बहत्तर छेद | जिसमें स्वयं अनेक दोष हों उसे दूसरों की आलोचना शोभा नहीं देती |

## 5. याद रखने की रणनीति

- मुहावरों को **समूह में** याद करें — शरीर के अंगों पर आधारित (आँख, हाथ, सिर, नाक, मुँह) मुहावरे साथ-साथ रटें, ये सबसे अधिक पूछे जाते हैं (सेक्शन 2)।
- लोकोक्तियों को **कहानी/संदर्भ सहित** याद करें — हर लोकोक्ति के पीछे एक संक्षिप्त लोक-कथा जैसा भाव होता है, वह याद रहने में मदद करता है।
- परीक्षा में सामान्यतः दो तरह से पूछा जाता है: **(क)** मुहावरा/लोकोक्ति देकर अर्थ पूछना, **(ख)** अर्थ देकर सही मुहावरा/लोकोक्ति पहचानने को कहना — दोनों तरह का अभ्यास करें (तालिका को उल्टा पढ़कर भी अभ्यास करें)।

## 6. अभ्यास हेतु उच्च-संभावना सूची (self-test)

| प्रश्न | उत्तर |
|---|---|
| "नाकों चने चबाना" का अर्थ | बहुत परेशान करना/होना |
| "नौ दो ग्यारह होना" का अर्थ | भाग जाना |
| "ऊँट के मुँह में जीरा" — यह मुहावरा है या लोकोक्ति? | लोकोक्ति (पूर्ण वाक्य, स्थिर रूप) |
| "आँखों में धूल झोंकना" — यह मुहावरा है या लोकोक्ति? | मुहावरा (अपूर्ण वाक्यांश, रूप बदलता है) |
| "जैसी करनी वैसी भरनी" का भाव | जैसा कर्म वैसा फल |
| "घर का भेदी लंका ढाए" का भाव | आंतरिक व्यक्ति ही अधिक नुकसान पहुँचाता है |

## 7. याद रखने योग्य सबसे महत्वपूर्ण बिंदु (परीक्षा-केंद्रित)

1. **मुहावरा बनाम लोकोक्ति** का अंतर (सेक्शन 1) पहले स्पष्ट करें — कई प्रश्न सीधे यही भेद पूछते हैं।
2. शरीर के अंगों पर आधारित मुहावरे (सेक्शन 2) सबसे अधिक बार दोहराए जाते हैं — इन्हें सबसे पहले पक्का करें।
3. मुहावरे का प्रयोग वाक्य में हमेशा **क्रिया के रूप में ढालकर** होता है — परीक्षा में "रिक्त स्थान में उपयुक्त मुहावरा भरिए" प्रकार के प्रश्नों में यह ध्यान रखें कि काल/वचन सही हो।
4. लोकोक्तियों में शब्दशः स्मरण आवश्यक है — इन्हें अपने शब्दों में बदलकर उत्तर देने से गलत माना जा सकता है, हमेशा मानक रूप याद रखें।
