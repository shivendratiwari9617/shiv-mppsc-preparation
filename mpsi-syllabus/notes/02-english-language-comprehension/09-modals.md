# Modals — Can/Could/May/Might/Must/Should/Would/Ought to

**Subject:** English Language Comprehension | **Section:** Grammar Fundamentals | **Exam relevance:** MPSI along with MPPSC, Vyapam/ESB, Patwari, MP Police — modal-choice fill-in-the-blank questions test fine shades of meaning (ability vs permission, obligation vs advice) that are easy to get wrong without a clear reference.

---

## 1. What are Modals?

**Modal verbs** (modal auxiliaries) are helping verbs expressing ability, possibility, permission, obligation, or advice. They are always followed by the **base form (V1)** of the main verb, never take "-s/-ed/-ing", and don't need "do/does/did" to form questions or negatives.

---

## 2. Each Modal — Functions and Examples

| Modal | Function | Example |
|---|---|---|
| **Can** | Ability (present) | She can swim. |
| | Permission (informal) | Can I use your pen? |
| | General possibility | It can be cold in December. |
| **Could** | Ability (past) | She could swim as a child. |
| | Permission (polite/formal) | Could I use your pen? |
| | Weaker possibility | It could rain today. |
| **May** | Permission (formal) | May I come in? |
| | Possibility (present/future, formal) | It may rain today. |
| | Wish/Prayer | May you live long! |
| **Might** | Weaker/more uncertain possibility than "may" | It might rain today. |
| **Must** | Strong obligation/necessity | You must submit the form by Friday. |
| | Logical deduction/certainty | He must be at home; the lights are on. |
| | Prohibition (must not) | You must not smoke here. |
| **Should** | Advice/recommendation | You should see a doctor. |
| | Weaker obligation than "must" | Students should be punctual. |
| | Expectation | The train should arrive by 5. |
| **Would** | Past habit | He would often visit us. |
| | Polite request | Would you please close the door? |
| | Conditional (2nd/3rd conditional) | If I were rich, I would travel the world. |
| | Past willingness (usually negative) | He would not listen to me. |
| **Ought to** | Moral obligation/duty (similar to "should," slightly stronger) | You ought to respect your elders. |
| **Shall** | Future (formal, with I/we) | I shall return. |
| | Offer/suggestion | Shall we begin? |
| | Legal/formal obligation | The tenant shall pay rent monthly. |
| **Will** | Future (general) | She will come tomorrow. |
| | Willingness/promise | I will help you. |
| | Request | Will you pass the salt? |

---

## 3. Key Grammar Rules for Modals

1. Always followed by the **base form (V1)** — no "to" in between (except "ought to").
2. **No "-s" is added** even with a third-person singular subject: "He can swim" (not "He cans swim").
3. Negatives are formed by adding "not" directly: cannot/can't, should not/shouldn't.
4. Questions are formed by **inversion**, with no "do/does" needed: "Can you swim?" (not "Do you can swim?").

---

## 4. Commonly Confused Modal Pairs (High-Yield)

| Pair | Distinction |
|---|---|
| **can vs could** | can = present ability/informal; could = past ability, or a more polite/formal request |
| **may vs might** | may = a relatively likely possibility; might = a weaker, more hypothetical possibility |
| **must vs should** | must = strong obligation/necessity; should = advice or a weaker recommendation |
| **must vs have to** | must = obligation from the **speaker's own judgment**; have to = obligation from an **external rule/authority** |
| **shall vs will** | shall traditionally used with I/we for plain future or formal/legal obligation; will used with all persons for future/willingness |

---

## 5. Semi-Modals (Related, Behave Partly Like Modals)

have to, need to, used to, ought to, dare to — these carry modal-like meaning but follow slightly different grammar (e.g., "have to" takes "do/does/did" for questions and negatives, unlike true modals).

---

## 6. Practice — High-Probability Self-Test

| Sentence | Correct modal |
|---|---|
| "You ___ respect your elders." (moral duty) | ought to |
| "___ I come in, sir?" (formal permission) | May |
| "It ___ rain later; the sky is very cloudy." (fairly likely) | may/might |
| "He ___ be at home; his car is in the driveway." (logical certainty) | must |
| "As a child, she ___ sing beautifully." (past ability) | could |
| "You ___ finish this by tomorrow." (external work deadline, not personal opinion) | have to |

---

## 7. Most Important Exam-Focused Points

1. **Must vs should** and **may vs might** are the two most frequently tested distinctions — obligation-strength and possibility-strength respectively.
2. **Must vs have to** is a subtle but commonly asked nuance — must = speaker's own conviction, have to = external requirement.
3. Never forget the **base-form-only rule (Section 3)** — a modal followed by "to + verb," "-ing," or a conjugated verb is an automatic error-spotting target (except "ought to," which uniquely requires "to").
4. This topic feeds directly into point 14 (Spotting errors) and point 16 (Fill in the blanks) — modal-choice questions appear constantly in both formats.
