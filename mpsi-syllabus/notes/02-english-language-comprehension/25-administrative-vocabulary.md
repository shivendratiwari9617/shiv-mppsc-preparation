# Common Administrative/Official English Vocabulary

**Subject:** English Language Comprehension | **Section:** Vocabulary / Correspondence | **Exam relevance:** MPSI (pupil police/administrative role) along with MPPSC, Vyapam/ESB, Patwari, MP Police — parallels Hindi point 24 (सरकारी/कार्यालयीन हिंदी शब्दावली); official-English questions and correspondence-based comprehension both draw on this.

---

## 1. General Administrative Vocabulary

| Term | Meaning |
|---|---|
| Circular | An official notice sent to multiple recipients |
| Notification | A formal public announcement, often of a rule/appointment |
| Memorandum (memo) | A written note/reminder for internal communication |
| Gazette | An official government publication of laws/notices |
| Resolution | A formal decision passed by a body/committee |
| Minutes (of meeting) | The official written record of what was discussed/decided |
| Draft | A preliminary/unfinished version of a document |
| Approval | Formal consent to proceed |
| Sanction | Official permission or authorization (often for funds) |
| Amendment | A formal change/correction to a rule or document |
| Provision | A clause or condition within a law/document |
| Annexure | An attached supplementary document |
| Enclosure | A document included along with a letter |
| Endorsement | An official confirmation or note added to a document |
| Confidential | Meant to be kept private/restricted |
| Ordinance | A law issued by an authority without full legislative process |
| Jurisdiction | The official authority/area over which power extends |
| Headquarters | The central administrative office |

## 5. Common Formal Correspondence Phrases

These fixed phrases appear repeatedly in official letters, memos, and correspondence-based comprehension questions.

| Phrase | Use |
|---|---|
| "With reference to your letter dated..." | Opening a reply to a prior communication |
| "I am directed to inform you that..." | Formal notification (writer acting on behalf of authority) |
| "This is to certify that..." | Opening line of a certificate |
| "Kindly do the needful." | Requesting appropriate action |
| "For your kind information and necessary action." | Closing note when forwarding information |
| "It is requested that..." | Formal request |
| "Please find enclosed herewith..." | Referring to an attached document |
| "I would be grateful if you could..." | Polite formal request |
| "Awaiting your favorable response." | Formal closing, expecting a reply |
| "Yours faithfully" | Formal letter closing (when the recipient's name isn't known — "Dear Sir/Madam") |
| "Yours sincerely" | Formal letter closing (when the recipient's name is known) |

## 6. Practice — High-Probability Self-Test

| Question | Answer |
|---|---|
| Official document confirming a fact | Certificate |
| Term for a temporary posting to another department | Deputation |
| First official record of a reported crime | FIR |
| Formal, sworn written statement | Affidavit |
| Phrase for requesting appropriate action in official letters | "Kindly do the needful." |
| Correct closing when the recipient's name is unknown | Yours faithfully |

---

## 7. Most Important Exam-Focused Points

1. The **police/legal vocabulary (Section 4)** carries special weight for MPSI given the Sub-Inspector role — these terms may appear in both language-comprehension and situational/administrative-awareness questions.
2. **Fixed correspondence phrases (Section 5)** are frequently tested in "choose the correct formal phrase" or letter-completion questions — memorize them as set expressions, not word-by-word translations.
3. "Yours faithfully" vs "Yours sincerely" (Section 5) is a small but recurring distinction — tied to whether the recipient is addressed by name.
4. This topic parallels Hindi point 24 directly — many of these English terms have the exact Hindi equivalents listed there (e.g., FIR = प्रथम सूचना प्रतिवेदन), so studying both together reinforces retention.
