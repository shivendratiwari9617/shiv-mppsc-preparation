# Spellings — Commonly Confused/Misspelled Words

**Subject:** English Language Comprehension | **Section:** Vocabulary / Spelling | **Exam relevance:** MPSI along with MPPSC, Vyapam/ESB, Patwari, MP Police — this parallels Hindi point 18 (वर्तनी); "choose the correctly spelled word" is a standard question type.

---

## 1. Common Spelling Rules

| Rule | Example |
|---|---|
| "i before e, except after c" | believe, receive, achieve, ceiling, deceive |
| Double the final consonant before a suffix (short stressed vowel + consonant) | stop → stopped, run → running, begin → beginning |
| "-able" vs "-ible" has no fixed rule — memorize | comfortable, acceptable vs visible, possible, responsible |
| Watch for silent letters | knowledge, foreign, receipt |

## 3. British vs American Spelling (Indian English Generally Follows British)

| British (used in Indian formal writing) | American |
|---|---|
| colour | color |
| favour | favor |
| centre | center |
| organise | organize |
| practise (verb) / practice (noun) | practice (both) |
| licence (noun) / license (verb) | license (both) |

**Note:** MPSI/MPPSC-level exams generally expect **British spelling** conventions, as this is standard in Indian formal/administrative English.

## 5. Most Important Exam-Focused Points

1. This is a **pure memorization topic**, like Hindi point 18 — no shortcut rule exists for most of these words; repeated exposure to the correct spelling is the only reliable method.
2. Focus first on the words most frequently mistested: **accommodate, separate, occurred, necessary, occasion, pronunciation, definitely** — these appear repeatedly across exam papers.
3. Be consistent with **British spelling conventions** (colour, organise, centre) unless the exam explicitly specifies American English.
4. This topic pairs with point 18 (Homophones and commonly confused words) — both are about precise word-form recognition, so studying them together reinforces both.
