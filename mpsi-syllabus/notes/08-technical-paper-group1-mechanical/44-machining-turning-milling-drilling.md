# Machining Processes — Turning, Milling, Drilling (मशीनिंग प्रक्रियाएं)

## Machining — Basic Concept

A **material removal** manufacturing process, where excess material is removed from a workpiece (using a cutting tool) to achieve the desired final shape, size, and surface finish — in contrast to casting/forming processes, which shape material without removal.

## Lathe Machine & Turning

### Turning — Basic Definition
A machining process performed on a **lathe**, in which the **workpiece rotates**, and a **single-point cutting tool** moves (feeds) linearly (parallel or at an angle to the axis) to remove material and produce a cylindrical (or contoured, revolved) shape.

### Main Parts of a Lathe
| Part | Function |
|---|---|
| **Bed** | The main structural base, supports/guides all other components |
| **Headstock** | Fixed end, houses the main spindle (holds/rotates the workpiece via a chuck) and speed-change gears |
| **Tailstock** | Movable, at the other end — supports the free end of long workpieces (via a centre) or holds tools like drills |
| **Carriage** | Moves along the bed, carries the cutting tool (via the cross-slide and tool post) |
| **Cross-Slide** | Mounted on the carriage, moves the tool **perpendicular** to the lathe axis (for facing, depth of cut) |
| **Tool Post** | Holds the cutting tool, mounted on the cross-slide |
| **Lead Screw** | A precision threaded shaft used to drive the carriage automatically during **thread cutting** |
| **Feed Rod** | A separate shaft used to drive the carriage for **general automatic feed** (turning, facing), distinct from the lead screw |
| **Chuck** | Clamping device on the headstock spindle, holds/rotates the workpiece (e.g., 3-jaw self-centring chuck, 4-jaw independent chuck) |

### Common Lathe Operations
**Turning (reducing diameter), Facing (machining the flat end face), Taper Turning, Thread Cutting, Knurling (producing a textured grip pattern), Boring (enlarging an existing internal hole), Drilling (using the tailstock), Parting-Off (cutting the finished piece off).**

## Milling

### Milling — Basic Definition
A machining process using a **rotating multi-point (multi-tooth) cutting tool** (the **milling cutter**), while the **workpiece is fed** against it (typically on a table that moves in multiple directions) — well-suited for producing flat surfaces, slots, grooves, and complex profiles.

### Types of Milling (by cutter-feed direction relationship)

| Type | Description |
|---|---|
| **Up (Conventional) Milling** | Cutter rotation is **opposite** to the direction of workpiece feed at the point of contact — chip thickness starts at **zero and increases** to maximum; more common/traditional, but produces a slightly rougher finish and tends to lift the workpiece |
| **Down (Climb) Milling** | Cutter rotation is in the **same** direction as workpiece feed — chip thickness starts at **maximum and decreases** to zero; gives a **better surface finish**, but requires a backlash-free feed mechanism (or the tool can "climb"/dig into the work if the machine has excessive backlash) |

### Types of Milling Machines
| Type | Description |
|---|---|
| **Horizontal Milling Machine** | Cutter spindle axis is **horizontal** — suited for slab/slot milling using cutters mounted on an arbor |
| **Vertical Milling Machine** | Cutter spindle axis is **vertical** — suited for end milling, face milling, drilling-type operations |
| **Universal Milling Machine** | Table can be **swivelled** (rotated in the horizontal plane), allowing angular/helical milling operations in addition to standard ones |

### Milling Cutter Types (brief)
**Plain (Slab) Milling Cutter, End Mill, Face Milling Cutter, Slot Drill, Form (Profile) Cutter, Gear Milling Cutter.**

## Drilling

### Drilling — Basic Definition
A machining process for producing (or enlarging) a **round hole**, using a **rotating drill bit** (typically a **twist drill**), while the drill is fed **axially** into the stationary (or, on a lathe, rotating) workpiece.

### Twist Drill — Key Features
- Has **two cutting edges (lips)** and **helical flutes** that carry the chips away from the cutting zone.
- **Point angle**: standard is **118°** for general-purpose drilling in most common materials (a specific, frequently tested numerical fact).
- **Web**: the central core of the drill body, providing rigidity.

### Related Hole-Making Operations

| Operation | Description |
|---|---|
| **Reaming** | A **finishing** operation, using a reamer to slightly enlarge and give a smooth, precise (accurate diameter/finish) surface to an already-drilled hole |
| **Boring** | Enlarging an **existing** hole (typically cast or already roughly drilled) to a precise diameter, using a single-point tool — unlike drilling, can correct hole misalignment/produce very accurate, large-diameter holes |
| **Counterboring** | Enlarging the **top portion** of a hole to a larger diameter, cylindrically, to seat a bolt head/washer below the surface |
| **Countersinking** | Enlarging the top of a hole into a **conical** shape, to seat a flat/countersunk screw head flush with the surface |
| **Spot Facing** | Machining a small flat circular area around a hole (on a rough/uneven surface), providing a proper seating surface for a bolt head/washer/nut |
| **Tapping** | Cutting **internal threads** into a drilled hole, using a **tap** |

## Cutting Speed, Feed & Depth of Cut — Basic Machining Parameters

| Parameter | Definition |
|---|---|
| **Cutting Speed (V)** | The speed at which the cutting edge moves relative to the workpiece surface — for turning, V = πDN/1000 (D = workpiece diameter in mm, N = rpm), giving V in m/min |
| **Feed (f)** | The distance the tool advances per revolution (turning) or per tooth/per minute (milling) |
| **Depth of Cut (d)** | The thickness of material removed in a single pass |

## Most Important Facts to Remember

- **Turning**: workpiece rotates, single-point tool feeds — done on a **lathe**. **Milling**: multi-point rotating cutter, workpiece feeds — done on a **milling machine**. **Drilling**: rotating drill bit fed axially, produces round holes.
- **Up milling**: chip thickness zero→max, cutter and feed direction opposite. **Down (climb) milling**: chip thickness max→zero, cutter and feed direction same, better finish.
- Standard **twist drill point angle = 118°** for general-purpose drilling.
- **Reaming** = finishing an already-drilled hole for accuracy/finish; **Boring** = enlarging/correcting an existing hole with a single-point tool (can fix misalignment, unlike drilling); **Tapping** = cutting internal threads.
- **Counterboring** = cylindrical recess (for bolt heads); **Countersinking** = conical recess (for flat-head screws) — a frequently confused pair.
- **Lead screw** (thread cutting) vs **Feed rod** (general automatic feed) on a lathe — distinct shafts serving distinct purposes.

## Practice Questions

1. What is the standard point angle of a general-purpose twist drill? → **118°**
2. What is the key difference between reaming and boring? → **Reaming is a light finishing operation for accuracy/surface finish on an already-drilled hole; boring uses a single-point tool to enlarge/correct an existing hole, and can correct misalignment**
3. Which type of milling gives a better surface finish — up milling or down (climb) milling? → **Down (climb) milling**
4. What is the difference between counterboring and countersinking? → **Counterboring creates a cylindrical recess (for a bolt head/washer); countersinking creates a conical recess (for a flat/countersunk screw head)**
